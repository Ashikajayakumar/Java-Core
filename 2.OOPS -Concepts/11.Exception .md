# 🔷 **Exception Handling in Java**

👉 **Exception Handling** is a mechanism to **handle runtime errors** so that the **normal flow of the program continues**.

---

# 🔷 What is an **Exception**?

👉 An **exception** is an **event** that:

* Occurs during **runtime**
* **Disrupts normal program flow**
* Is represented as an **object**

---

## ✅ Example

```java id="ex1"
int a = 10 / 0; // ArithmeticException
```

---

# 🔷 Types of Exceptions in Java

## ✅ 1. **Checked Exception**

* Checked at **compile-time**
* Must be handled using **try-catch** or `throws`

### 🔸 Examples:

* `IOException`
* `SQLException`

---

## ✅ 2. **Unchecked Exception** (Runtime Exception)

* Occurs at **runtime**
* Not checked at compile-time

### 🔸 Examples:

* `ArithmeticException`
* `NullPointerException`
* `ArrayIndexOutOfBoundsException`

---

## ✅ 3. **Error**

* **Irrecoverable**
* Caused by system issues

### 🔸 Examples:

* `OutOfMemoryError`
* `VirtualMachineError`

---

# 🔷 Difference: Checked vs Unchecked

| Feature      | **Checked**  | **Unchecked**        |
| ------------ | ------------ | -------------------- |
| Checked at   | Compile-time | Runtime              |
| Handling     | Mandatory    | Optional             |
| Parent Class | Exception    | RuntimeException     |
| Example      | IOException  | NullPointerException |

---

# 🔷 Java **try-catch** Block

👉 Used to **handle exceptions**

---

## ✅ Syntax

```java id="ex2"
try {
    // risky code
} catch (Exception e) {
    // handling code
}
```

---

## ✅ Example

```java id="ex3"
public class Demo {
    public static void main(String[] args) {
        try {
            int a = 10 / 0;
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }
    }
}
```

---

# 🔷 **catch Block**

* Handles the exception
* Must come **after try**

---

# 🔷 Multiple Catch Blocks

```java id="ex4"
try {
    int arr[] = new int[5];
    arr[10] = 50;
} catch (ArithmeticException e) {
    System.out.println("Arithmetic Error");
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("Array Error");
}
```

---

# 🔷 Multi-Catch (Java 7+)

```java id="ex5"
try {
    int a = 10 / 0;
} catch (ArithmeticException | NullPointerException e) {
    System.out.println("Handled multiple exceptions");
}
```

---

# 🔷 Nested try Block

👉 try block inside another try block

---

## ✅ Example

```java id="ex6"
try {
    try {
        int a = 10 / 0;
    } catch (ArithmeticException e) {
        System.out.println("Inner catch");
    }
} catch (Exception e) {
    System.out.println("Outer catch");
}
```

---

## 🔥 Why Nested try?

✔ Different parts of code may throw **different exceptions**
✔ Allows **separate handling**
