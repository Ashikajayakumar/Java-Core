

# 🔷 Inheritance in Java

## 🧩 What is Inheritance?

**Inheritance** is a mechanism in which one class **acquires properties and behaviors** of another class.
```
✔ Represents **IS-A relationship**
✔ Also called **parent-child relationship**
✔ Inheritance can be done by **etends**
```
---

## 🔷 Terminology

* **Superclass (Parent Class)** → class whose properties are inherited
* **Subclass (Child Class)** → class that inherits

---

## ✅ Example

```java
class Animal {
    void eat() {
        System.out.println("Eating...");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking...");
    }
}
```

---

# 🔷 Why use Inheritance?
```
✔ **Code Reusability**
✔ **Method Overriding** (Runtime Polymorphism)
✔ **Reduce redundancy**
✔ **Improve maintainability**
```
---

# 🔷 Types of Inheritance in Java

👉 Based on classes, Java supports:

* **Single**
* **Multilevel**
* **Hierarchical**

👉 (Multiple inheritance not supported with classes ❌)

# 🔷 Why Multiple Inheritance NOT Supported?

❌ Causes **ambiguity problem (Diamond Problem)**
❌ Increases **complexity**

👉 Java solves this using **interfaces**

# 🔷 Association in Java

👉 **Association** = relationship between classes

---

## 🔷 Types of Association

### 1. **Aggregation** (HAS-A, weak relationship)

✔ One class contains reference of another
✔ Objects are **independent**

---

### ✅ Example

```java
class Address {
    String city;

    Address(String city) {
        this.city = city;
    }
}

class Student {
    Address addr; // aggregation

    Student(Address addr) {
        this.addr = addr;
    }
}
```

---

### 2. **Composition** (Strong relationship)

✔ Strong HAS-A relationship
✔ Dependent objects (cannot exist independently)

---

### ✅ Example

```java
class Engine {}

class Car {
    private Engine engine = new Engine(); // composition
}
```

---

# 🔷 Key Difference: Aggregation vs Composition

| Feature      | Aggregation     | Composition |
| ------------ | --------------- | ----------- |
| Relationship | Weak            | Strong      |
| Dependency   | Independent     | Dependent   |
| Example      | Student–Address | Car–Engine  |
