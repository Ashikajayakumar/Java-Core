# 🔷 Java **static** Keyword

The **static keyword** in Java is mainly used for **memory management**.

* It belongs to the **class**, not to the **object (instance)**
* It can be used with:

* **Variables**
* **Methods**
* **Blocks**
* **Nested classes**

---

# 🔷 1. **Static Variable**

A variable declared with **static** is called a **static variable**.

### ✅ Key Points

* Belongs to the **class** (not object)
* **Single copy** shared by all objects
* Memory allocated **only once** in **class area (method area)**

---

### ✅ Example

```java id="b1d9qp"
class Student {
    int id;
    static String college = "ABC"; // static variable
}
```

---



# 🔷 2. **Static Method**

A method declared with **static** is called a **static method**.

---

### ✅ Key Points

* Belongs to **class**
* Can be called **without creating object**
* Can access only **static variables directly**

---

### ✅ Example

```java id="u7o3ho"
class Demo {
    static void show() {
        System.out.println("Static method");
    }

    public static void main(String[] args) {
        Demo.show(); // no object needed
    }
}
```

```

✔ JVM calls `main()` **without creating object**
✔ Avoids **extra memory usage**
✔ Makes program execution **simple and fast**
```
---

# 🔷 3. **Static Block**

A **static block** is used to **initialize static variables**.

---

### ✅ Key Points

* Executed **once**
* Runs **before main() method**
* Executed at **class loading time**

---

### ✅ Example

```java id="1u9tvd"
class Test {
    static {
        System.out.println("Static block executed");
    }

    public static void main(String[] args) {
        System.out.println("Main method");
    }
}
```

---

### ✅ Output

```
Static block executed
Main method
```

---

# 🔷 ❓ Can we run program without `main()`?

* ❌ **No (from JDK 1.7 onwards)**
* Earlier (JDK 1.6), static block trick worked

# 🔷 `this` Keyword in Java

The **`this` keyword** is a **reference variable** that refers to the **current object**.

---

## ✅ Uses of `this`

### 1. Refer current object variable

```java id="kgdz0k"
class Student {
    int id;

    Student(int id) {
        this.id = id; // resolves confusion
    }
}
```

---

### 2. Call current class method

```java id="zv9rkk"
void display() {
    this.show();
}
```

---

### 3. Call constructor (constructor chaining)

```java id="3o6xts"
class Test {
    Test() {
        this(10);
        System.out.println("Default");
    }

    Test(int x) {
        System.out.println("Parameterized");
    }
}
```

---

### 4. Pass current object as argument

```java id="1c84i5"
void display(Test obj) {}
display(this);
```

# 🔥 Static vs Instance in Java

## 🧩 Basic Idea

* **Static** → belongs to the **class**
* **Instance** → belongs to the **object**

---

# 🔷 Static vs Instance (Comparison Table)

| Feature        | **Static**                                  | **Instance**                          |
| -------------- | ------------------------------------------- | ------------------------------------- |
| Belongs to     | **Class**                                   | **Object**                            |
| Memory         | **Allocated once** (Class area)             | **Allocated per object** (Heap)       |
| Access         | Using **class name**                        | Using **object reference**            |
| Copy           | **Single copy shared**                      | **Separate copy for each object**     |
| Method Access  | Can access only **static members** directly | Can access **both static & instance** |
| `this` keyword | ❌ Not allowed                               | ✅ Allowed                             |
| Execution      | Loaded at **class loading time**            | Created at **object creation**        |
