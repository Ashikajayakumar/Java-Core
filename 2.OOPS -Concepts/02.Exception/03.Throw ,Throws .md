# 🔷 What is **`throw` keyword** in Java?

The **`throw` keyword** is used to **explicitly throw an exception**.
<img width="1024" height="1536" alt="image" src="https://github.com/user-attachments/assets/dda7b137-9cfc-44f3-99c1-b2a9ed789da7" />

---

## ✅ Key Points

* ✔ Used **inside method/block**
* ✔ Throws **one exception at a time**
* ✔ Used for:

* Built-in exceptions
* **Custom exceptions**

---

## ✅ Example

```java id="th1"
public class Test {
    public static void main(String[] args) {
        int age = 15;

        if (age < 18) {
            throw new ArithmeticException("Not eligible");
        }

        System.out.println("Eligible");
    }
}
```

---

## ✅ Output

```id="th2"
Exception in thread "main" java.lang.ArithmeticException: Not eligible
```

---

## 🔍 Explanation

* Condition is true → `throw` executes
* Exception is created manually
* Program stops ❌

# 🔷 Java **Exception Propagation**

👉 When an exception is **not handled**, it is passed to the **calling method**.

---

## ✅ Example

```java id="prop1"
class Test {
    void m1() {
        int a = 10 / 0;
    }

    void m2() {
        m1();
    }

    void m3() {
        m2();
    }

    public static void main(String[] args) {
        Test t = new Test();
        t.m3();
    }
}
```

---

## ✅ Output

```id="prop2"
Exception in thread "main" java.lang.ArithmeticException
```

---

## 🔍 Explanation

* Error occurs in `m1()`
* Passed to `m2()` → `m3()` → `main()`
* Not handled → program crashes

# 🔷 What is **`throws` keyword**?

The **`throws` keyword** is used to **declare exceptions**.

👉 It tells the compiler:

> “This method may throw an exception”

---

## ✅ Syntax

```java id="ths1"
void methodName() throws ExceptionType {
    // code
}
```

---

## ✅ Example

```java id="ths2"
import java.io.*;

class Test {
    void readFile() throws IOException {
        FileReader f = new FileReader("abc.txt");
    }

    public static void main(String[] args) throws IOException {
        Test t = new Test();
        t.readFile();
    }
}
```

---

# 🔷 Difference: **throw vs throws**

| Feature  | **throw**                | **throws**                  |
| -------- | ------------------------ | --------------------------- |
| Type     | Keyword                  | Keyword                     |
| Use      | Throw exception          | Declare exception           |
| Location | Inside method            | Method signature            |
| Number   | One exception            | Multiple exceptions         |
| Example  | `throw new Exception();` | `void m() throws Exception` |

---

# 🔷 Example with Both

```java id="both1"
class Test {
    void checkAge(int age) throws Exception {
        if (age < 18) {
            throw new Exception("Not eligible");
        }
    }

    public static void main(String[] args) throws Exception {
        Test t = new Test();
        t.checkAge(15);
    }
}
```
