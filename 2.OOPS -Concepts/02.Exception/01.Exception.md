# 🔷 What is **Exception Handling**?
    
**Exception Handling** is a mechanism to **handle runtime errors** so that the **program does not crash** and the **normal flow continues**.      
      
---   

## 🧩 What is an Exception?

👉 An **exception** is an **event (error)** that occurs at **runtime** and **interrupts program execution**. 
 
---

## ❌ Without Exception Handling

```java id="noex1"
public class Test {
    public static void main(String[] args) {
        int a = 10 / 0; // error
        System.out.println("End");
    }
}
```

### 🔴 Output

```id="noex2"
Exception in thread "main" java.lang.ArithmeticException
```

👉 Program stops ❌
👉 `"End"` is NOT printed

---

# 🔷 Why Exception Handling?

* Prevents program crash
* Maintains **normal flow**
* Handles errors **gracefully**
* Improves **program reliability**

---

# 🔷 Types of Exceptions

## ✅ 1. Checked Exception (Compile-time)

* Checked by compiler
* Must be handled

Examples:

* `IOException`
* `SQLException`

---

## ✅ 2. Unchecked Exception (Runtime)

* Occurs at runtime
* Not checked at compile time

Examples:

* `ArithmeticException`
* `NullPointerException`
* `ArrayIndexOutOfBoundsException`

---

## ❌ 3. Error

* Serious problem
* Cannot be handled normally

Examples:

* `OutOfMemoryError`
* `StackOverflowError`

---

# 🔷 try-catch Block

## ✅ Syntax

```java id="try1"
try {
    // risky code
} catch(Exception e) {
    // handling code
}
```

---

## ✅ Example with Output

```java id="try2"
public class Test {
    public static void main(String[] args) {
        try {
            int a = 10 / 0;
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }
        System.out.println("Program continues");
    }
}
```

---

### ✅ Output

```id="try3"
Cannot divide by zero
Program continues
```

---

## 🔍 Explanation

* `10/0` → causes **exception**
* `catch` block handles it
* Program continues normally ✅

---

# 🔷 Multiple Catch (Multi-catch)

```java id="mc1"
public class Test {
    public static void main(String[] args) {
        try {
            int arr[] = new int[5];
            arr[10] = 50;
        } catch (ArithmeticException e) {
            System.out.println("Arithmetic error");
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Array index error");
        }
    }
}
```

---

### ✅ Output

```id="mc2"
Array index error
```

---

## 🔍 Explanation

* Error is **ArrayIndexOutOfBounds**
* Matching catch block executes

---

# 🔷 Nested try Block

👉 try inside another try

---

## ✅ Example

```java id="nt1"
public class Test {
    public static void main(String[] args) {
        try {
            try {
                int a = 10 / 0;
            } catch (ArithmeticException e) {
                System.out.println("Inner catch: Divide by zero");
            }

            int arr[] = new int[5];
            arr[10] = 10;

        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Outer catch: Array error");
        }
    }
}
```

---

### ✅ Output

```id="nt2"
Inner catch: Divide by zero
Outer catch: Array error
```
