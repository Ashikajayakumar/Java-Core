# 🔷 What is **Exception Handling**?    
     
**Exception Handling** is a mechanism to **handle runtime errors** so that the **program does not crash** and the **normal flow continues**.           
             
---       
  
## 🧩 What is an Exception? 

👉 An **exception** is an **event (error)** that occurs at **runtime** and **interrupts program execution**. 
 
---

## ❌ Without Exception Handling

```java id="noex1"
public class Test {
    public static void main(String[] args) {
        int a = 10 / 0; // error
        System.out.println("End");
    }
}
```

### 🔴 Output

```id="noex2"
Exception in thread "main" java.lang.ArithmeticException
```

👉 Program stops ❌
👉 `"End"` is NOT printed

---

# 🔷 Why Exception Handling?

* Prevents program crash
* Maintains **normal flow**
* Handles errors **gracefully**
* Improves **program reliability**

# 🔷 Checked vs Unchecked Exception — How to Use

## 1. ✅ Checked Exception

A **checked exception** is checked by the compiler.

If a method can produce a checked exception, you must either:

1. Handle it using `try-catch`, **or**
2. Declare it using `throws`.

### Example: `FileNotFoundException`

```
import java.io.*;

public class Test {
    public static void main(String[] args) {

        try {
            FileReader file = new FileReader("data.txt");
            System.out.println("File opened");
        }
        catch (FileNotFoundException e) {
            System.out.println("File not found");
        }

        System.out.println("Program continues");
    }
}

```

### Output if file doesn't exist:

```
File not found
Program continues

```

### Why `try-catch` is required?

Because `FileReader` can throw a **checked exception**.

The compiler gives an error if you don't handle it:

```
FileReader file = new FileReader("data.txt");

```

❌ Compiler says you need to handle `FileNotFoundException`.

---

# 🔷 Another Way: `throws`

Instead of handling it with `try-catch`, you can pass the responsibility to the caller.

```
import java.io.*;

public class Test {

    static void readFile() throws FileNotFoundException {
        FileReader file = new FileReader("data.txt");
    }

    public static void main(String[] args) {

        try {
            readFile();
        }
        catch (FileNotFoundException e) {
            System.out.println("File not found");
        }
    }
}

```

Here:

```
throws FileNotFoundException

```

means:

> "This method may produce `FileNotFoundException`; whoever calls this method must handle it."

---

# 🔷 2. ❌ Unchecked Exception

An **unchecked exception** is **not checked by the compiler**.

These usually occur because of programming mistakes or invalid runtime data.

Examples:

```
ArithmeticException
NullPointerException
ArrayIndexOutOfBoundsException
NumberFormatException

```

### Example

```
public class Test {
    public static void main(String[] args) {

        try {
            int a = 10 / 0;
        }
        catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }

        System.out.println("Program continues");
    }
}

```

Output:

```
Cannot divide by zero
Program continues

```

Here `try-catch` is **not compulsory**.

You can write:

```
int a = 10 / 0;

```

and Java will compile it.

But when the program runs:

```
ArithmeticException

```

occurs.





### One-line memory trick:

**Checked → compiler forces you to handle/declare.**

**Unchecked → compiler doesn't force you; exception appears at runtime.**

# 🔷 Nested try Block 
 
👉 try inside another try 
 
--- 
 
## ✅ Example 
 
```java id="nt1" 
public class Test { 
    public static void main(String[] args) { 
        try { 
            try { 
                int a = 10 / 0; 
            } catch (ArithmeticException e) { 
                System.out.println("Inner catch: Divide by zero"); 
            } 
 
            int arr[] = new int[5]; 
            arr[10] = 10; 
 
        } catch (ArrayIndexOutOfBoundsException e) { 
            System.out.println("Outer catch: Array error"); 
        } 
    } 
} 
``` 
 
--- 
 
### ✅ Output 
 
```id="nt2" 
Inner catch: Divide by zero 
Outer catch: Array error 
```
