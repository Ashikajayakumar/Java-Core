# 🔷 What is **finally block** in Java?

The **`finally` block** is used to execute **important code** (like closing resources), **whether exception occurs or not**.

---

## ✅ Key Points

* Always executes (almost always — see note below ⚠)
* Used for **cleanup code**
* Comes after **try-catch**

---

## 🔷 Syntax

```java id="fin1"
try {
    // risky code
} catch (Exception e) {
    // handle exception
} finally {
    // always executed
}
```

---

# 🔷 Example 1 (Exception occurs)

```java id="fin2"
public class Test {
    public static void main(String[] args) {
        try {
            int a = 10 / 0;
        } catch (ArithmeticException e) {
            System.out.println("Exception handled");
        } finally {
            System.out.println("Finally block executed");
        }
    }
}
```

---

## ✅ Output

```id="fin3"
Exception handled
Finally block executed
```

---

# 🔷 Example 2 (No Exception)

```java id="fin4"
public class Test {
    public static void main(String[] args) {
        try {
            int a = 10 / 2;
            System.out.println(a);
        } catch (Exception e) {
            System.out.println("Exception");
        } finally {
            System.out.println("Finally block executed");
        }
    }
}
```

---

## ✅ Output

```id="fin5"
5
Finally block executed
```

---

# 🔷 Why use finally?

* Close files
* Close database connections
* Release resources
*  Important statements always executed

---

# ⚠ Important Exception (Interview Point)

👉 `finally` **may not execute** if:

* `System.exit()` is called
* JVM crashes

---

# 🔷 Difference: **final vs finally vs finalize**

| Feature   | **final**                        | **finally**         | **finalize()**                 |
| --------- | -------------------------------- | ------------------- | ------------------------------ |
| Type      | Keyword                          | Block               | Method                         |
| Use       | Restrict changes                 | Cleanup code        | Garbage collection             |
| Used with | Variable, method, class          | try-catch           | Object class                   |
| Example   | `final int x = 10;`              | `finally {}`        | `protected void finalize()`    |
| Purpose   | Make constant / prevent override | Always execute code | Called before object destroyed |

---

# 🔷 Quick Examples

## ✅ final

```java id="f1"
final int x = 10;
// x = 20; ❌
```

---

## ✅ finally

```java id="f2"
try {
    int a = 10 / 0;
} finally {
    System.out.println("Always runs");
}
```

---

## ✅ finalize()

```java id="f3"
class Test {
    protected void finalize() {
        System.out.println("Object destroyed");
    }
}
```
