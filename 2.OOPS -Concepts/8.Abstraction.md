# 🔷 What is an **Abstract Method**?

An **abstract method** is a method that:

* Has **no body (no implementation)**
* Declared using **`abstract` keyword**
* Must be **implemented by child class**

---

## ✅ Example

```java
abstract class Vehicle {
    abstract void start(); // abstract method
}
```

---

# 🔷 What is **Abstraction**?

👉 **Abstraction = hiding internal details and showing only essential features**

✔ Focus on **what to do**, not **how to do**

---

## ✅ Real-Life Example

🚗 Car:

* You use **accelerator, brake**
* You don’t know **engine working internally**

👉 That is **abstraction**

---

# 🔷 Why Abstraction?

* **Reduces complexity**
* **Improves security** (hides data)
* **Easy to use**
* Helps in **large application design**
* Supports **loose coupling**

---

# 🔷 How to Achieve Abstraction in Java?

👉 There are **2 ways**:

---

## ✅ 1. Using **Abstract Class**

```java
abstract class Animal {
    abstract void sound(); // abstract method

    void sleep() {
        System.out.println("Sleeping...");
    }
}
```

---

## ✅ 2. Using **Interface**

```java
interface Animal {
    void sound(); // abstract by default
}
```

---

# 🔷 Connection with Your Diagram

Your diagram shows:

```
+-----------------------------+
| class  ----extends----> class |
+-----------------------------+

+-----------------------------+
| class ----implements--> interface |
+-----------------------------+

+-----------------------------+
| interface ----extends--> interface |
+-----------------------------+
```

---

## 🔥 Meaning:

### ✔ Class → Class

👉 Uses **extends** (Inheritance)

---

### ✔ Class → Interface

👉 Uses **implements**

```java
class Dog implements Animal
```

---

### ✔ Interface → Interface

👉 Uses **extends**

```java
interface A {}
interface B extends A {}
```

---

# 🔷 Complete Example (Abstraction + Interface)

```java
interface Shape {
    void draw(); // abstract
}

class Circle implements Shape {
    public void draw() {
        System.out.println("Drawing Circle");
    }
}
```
