# 🔹 1. Naming a Thread in Java

---

## 🔹 What is Thread Naming?

Every thread in Java has a **default name** given by JVM:

```
Thread-0, Thread-1, Thread-2 ...
```

👉 We can also **change or set custom names** for better identification.

---

## 🔹 Why naming is important?

* ✔ Debugging multithreaded programs
* ✔ Tracking thread execution
* ✔ Real-world applications (logs, servers)

---

## 🔹 Thread Naming Methods

### 1️⃣ `getName()`

👉 Returns the name of the thread

```java id="1v2g8a"
Thread t = new Thread();
System.out.println(t.getName());
```

✔ Output:

```
Thread-0
```

---

### 2️⃣ `setName(String name)`

👉 Used to change thread name

```java id="8kqz3m"
Thread t = new Thread();
t.setName("MyThread");

System.out.println(t.getName());
```

✔ Output:

```
MyThread
```

---

## 🔹 Real Example

```java id="thread_name_ex"
class MyThread extends Thread {
    public void run() {
        System.out.println("Running: " + getName());
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        t1.setName("Worker-1");
        t1.start();
    }
}
```

# 🔹 2. Current Thread in Java

---

## 🔹 What is currentThread()?

👉 It returns the **currently executing thread**

```java id="current_thread"
Thread.currentThread();
```

---

## 🔹 Syntax:

```java
public static Thread currentThread()
```

---

## 🔹 Example:

```java id="cur_thread_ex"
class MyThread extends Thread {
    public void run() {
        System.out.println(Thread.currentThread().getName());
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        t1.setName("MyWorker");
        t1.start();
    }
}
```

✔ Output:

```
MyWorker
```

# 🔹 3. Thread Priority in Java

---

## 🔹 What is Thread Priority?

Each thread has a priority from:

```
1 to 10
```

👉 It tells scheduler which thread should get more CPU chance.

---

## 🔹 Priority Levels

| Constant      | Value | Meaning          |
| ------------- | ----- | ---------------- |
| MIN_PRIORITY  | 1     | Lowest priority  |
| NORM_PRIORITY | 5     | Default priority |
| MAX_PRIORITY  | 10    | Highest priority |

---

## 🔹 Default Priority

```
NORM_PRIORITY = 5
```

---

# 🔹 4. Priority Methods

---

## 🔹 1. getPriority()

👉 Returns thread priority

```java id="get_priority"
Thread t = new Thread();
System.out.println(t.getPriority());
```

✔ Output:

```
5
```

---

## 🔹 2. setPriority(int value)

👉 Sets thread priority

```java id="set_priority"
Thread t = new Thread();
t.setPriority(8);
System.out.println(t.getPriority());
```

---

## ⚠️ Important Rule

```text
Priority must be between 1 and 10
```

Otherwise:

👉 `IllegalArgumentException`

---

# 🔹 5. Example Program (Naming + Priority + Current Thread)

```java id="full_thread_ex"
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread Name: " + getName());
        System.out.println("Priority: " + getPriority());
        System.out.println("Current Thread: " + Thread.currentThread().getName());
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();

        t1.setName("WorkerThread");
        t1.setPriority(8);

        t1.start();
    }
}
```

---

## ✔ Output:

```
Thread Name: WorkerThread
Priority: 8
Current Thread: WorkerThread
```
