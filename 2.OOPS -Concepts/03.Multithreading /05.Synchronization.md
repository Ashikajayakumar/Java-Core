# 🔷 Synchronization in Java

**Synchronization** is a mechanism used in Java to control access to a **shared resource** when multiple threads are running at the same time.

### Simple definition

> **Synchronization allows only one thread at a time to access a critical section of code, preventing data inconsistency.**

### Why do we need synchronization?

Suppose **2 people try to book the same bus seat at the same time**.

```text
Bus Seat = 1 available

Person 1 ──→ Check seat ──→ Available
Person 2 ──→ Check seat ──→ Available

Both try to book the same seat ❌

Result → Data inconsistency
```

We need synchronization:

```text
             Shared Seat
                 │
        ┌────────┴────────┐
        ↓                 ↓
    Thread 1          Thread 2
        │                 │
    🔒 Access        ⏳ Wait
        │
    Book seat
        │
    🔓 Release
                          │
                       Access
                          │
                       Seat unavailable
```

So, **Thread 1 completes the booking first**, and Thread 2 gets the updated value.

---

# 🔷 Example: Without Synchronization

```java
class Bus {

    int seats = 1;

    void bookSeat() {

        if (seats > 0) {

            System.out.println(
                Thread.currentThread().getName()
                + " is booking the seat"
            );

            seats--;
        }
        else {
            System.out.println("Seat not available");
        }
    }
}
```

Two threads:

```java
public class Main {

    public static void main(String[] args) {

        Bus bus = new Bus();

        Thread t1 = new Thread(() -> bus.bookSeat(), "Person 1");
        Thread t2 = new Thread(() -> bus.bookSeat(), "Person 2");

        t1.start();
        t2.start();
    }
}
```

Both threads access the **same `Bus` object**.

The problem is that both threads can check:

```java
if (seats > 0)
```

before either thread decreases `seats`.

Therefore, both may think:

```text
Seat available ✅
```

This is called a **race condition**, which can lead to **data inconsistency**.

---

# 🔷 With Synchronization

We can use the `synchronized` keyword:

```java
class Bus {

    int seats = 1;

    synchronized void bookSeat() {

        if (seats > 0) {

            System.out.println(
                Thread.currentThread().getName()
                + " is booking the seat"
            );

            seats--;
        }
        else {
            System.out.println("Seat not available");
        }
    }
}
```

### What happens now?

```text
Person 1 → 🔒 enters bookSeat()
              ↓
           books seat
              ↓
           seats = 0
              ↓
          🔓 releases lock

Person 2 → 🔒 enters bookSeat()
              ↓
           seats = 0
              ↓
        Seat not available
```

Only **one thread at a time** can execute the synchronized method for the same object.
