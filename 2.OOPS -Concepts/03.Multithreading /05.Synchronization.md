## 🔹 What is Data Inconsistency?

When **multiple threads access and modify the same shared data at the same time**, the final result becomes **incorrect or unpredictable**.

👉 This problem is called **Data Inconsistency**.

---

## 🔥 Why does it happen?

Because:

* ✔ Threads run simultaneously
* ✔ No control over shared resource access
* ✔ One thread overwrites another thread’s data

---

## 🔹 Real-Life Example

Imagine:

👉 Two people booking the same bus seat

* Person A selects seat
* Person B also selects same seat at same time

❌ Result: same seat booked twice → inconsistency

---

# 🔷 Solution: Synchronization in Java

---

## 🔹 What is Synchronization?

Synchronization is a **mechanism in Java that controls access to shared resources by multiple threads**.

👉 Only **one thread can access the synchronized block/method at a time**

---

## 🔹 Why Synchronization is needed?

* ✔ To avoid data inconsistency
* ✔ To maintain thread safety
* ✔ To control shared resource access

---

# 🔷 How Synchronization Works

When a thread enters a synchronized method:

👉 It locks the object
👉 Other threads must wait
👉 After completion → lock is released

---

# 🔷 Types of Synchronization

## 1️⃣ Method Synchronization

```java id="sync_method"
class Web {
    synchronized void show(String name) {
        for(int i = 0; i < 5; i++) {
            System.out.println("Welcome " + name);

            try {
                Thread.sleep(1000);
            } catch (Exception e) {
                System.out.println(e);
            }
        }
    }
}
```

---

## 2️⃣ Block Synchronization

```java id="sync_block"
class Web {
    void show(String name) {
        synchronized(this) {
            for(int i = 0; i < 5; i++) {
                System.out.println("Welcome " + name);

                try {
                    Thread.sleep(1000);
                } catch (Exception e) {}
            }
        }
    }
}
```

---

# 🔷 Thread Class

```java id="thread_class"
class User extends Thread {
    Web obj;
    String name;

    User(Web obj, String name) {
        this.obj = obj;
        this.name = name;
    }

    public void run() {
        obj.show(name);
    }
}
```

---

# 🔷 Main Class

```java id="main_sync"
public class Main {
    public static void main(String[] args) {

        Web obj = new Web();

        User t1 = new User(obj, "User1");
        User t2 = new User(obj, "User2");

        t1.start();
        t2.start();
    }
}
```

---

# 🔷 Without Synchronization (Problem ❌)

Output becomes mixed:

```text id="bad_output"
Welcome User1
Welcome User2
Welcome User1
Welcome User2
```

👉 This is **data inconsistency**

---

# 🔷 With Synchronization (Solution ✔)

Output becomes correct:

```text id="good_output"
Welcome User1
Welcome User1
Welcome User1
...
Welcome User2
Welcome User2
```
