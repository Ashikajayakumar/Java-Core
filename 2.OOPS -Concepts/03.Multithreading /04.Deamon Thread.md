# 🔷 Daemon Thread in Java

---

# 🔹 What is a Daemon Thread?

A **Daemon Thread** is a background service thread in Java that provides services to **user threads**.

👉 It runs in the background and supports main tasks.

✔ It does NOT perform core application logic.

---

# 🔹 Key Concept

👉 **Daemon thread depends on user threads**

✔ If all user threads finish → JVM automatically stops daemon threads

---

# 🔹 Why JVM stops Daemon Threads?

The purpose of daemon threads is only to support user threads.

👉 If no user thread is running:

* ✔ There is no work left
* ✔ So JVM terminates daemon threads automatically

---

# 🔹 Examples of Daemon Threads in Java

Java already uses daemon threads internally:

* ✔ Garbage Collector (GC)
* ✔ Finalizer thread
* ✔ Background monitoring threads

---



# 🔹 Daemon Thread Method

## 🔸 `setDaemon(true)`

👉 Used to make a thread daemon

```java id="daemon_set"
Thread t = new Thread();
t.setDaemon(true);
```

---

## 🔸 `isDaemon()`

👉 Checks if thread is daemon

```java id="daemon_check"
System.out.println(t.isDaemon());
```

---

# ⚠️ Important Rule

👉 `setDaemon(true)` must be called **before start()**

Otherwise:

```text id="error"
IllegalThreadStateException
```

---

# 🔷 Example Program

```java id="daemon_example"
class MyThread extends Thread {
    public void run() {
        while(true) {
            System.out.println("Daemon thread running...");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();

        t1.setDaemon(true); // make daemon thread
        t1.start();

        System.out.println("Main thread finished");
    }
}
```

---

# 🔹 Output Behavior

```text id="output_behavior"
Main thread finished
Daemon thread running...
Daemon thread running...
(then JVM exits automatically)
```

👉 After main thread ends → JVM stops daemon thread

---

# 🔷 Life Cycle Comparison

| Feature      | User Thread           | Daemon Thread       |
| ------------ | --------------------- | ------------------- |
| Purpose      | Main work             | Background support  |
| JVM behavior | Waits until finish    | Stops automatically |
| Priority     | Normal                | Low                 |
| Example      | main(), worker thread | GC, monitoring      |

---



# 🔷 Why Daemon Threads are useful?

* ✔ Background cleanup
* ✔ Memory management (GC)
* ✔ System monitoring
* ✔ Logging services

---

# 🔷 Key Interview Points 🔥

* ✔ Daemon thread supports user threads
* ✔ JVM terminates daemon threads automatically
* ✔ Must call `setDaemon(true)` before `start()`
* ✔ GC is a daemon thread
* ✔ Not used for main logic

---

# 🔷 Common Mistake ❌

```java
t.start();
t.setDaemon(true); // ❌ wrong
```

✔ Correct:

```java
t.setDaemon(true);
t.start();
```
