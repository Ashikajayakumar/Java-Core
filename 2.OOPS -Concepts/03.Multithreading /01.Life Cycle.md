# 1. What is Multitasking?

**Multitasking** means performing multiple tasks at the same time.

### Real-life example

You are using a computer:

* 🎵 Playing music
* 🌐 Browsing Chrome
* 📄 Editing a document
* 📥 Downloading a file

All these tasks appear to happen simultaneously.

In Java, multitasking is mainly achieved using **threads**.

---

# 2. Types of Multitasking

There are mainly **2 types**:

### 1. Process-based multitasking

Multiple **processes/programs** execute at the same time.

Example:

```text
Chrome       → Process
MS Word      → Process
VLC Player   → Process
```

Each process has its own memory.

---

### 2. Thread-based multitasking

Multiple **threads inside a single program** execute concurrently.

Example:

```text
Java Program
     |
     |--- Thread 1 → Download file
     |
     |--- Thread 2 → Play music
     |
     |--- Thread 3 → Display data
```

Java mainly uses **thread-based multitasking**.

---

# 3. What is a Thread?

A **thread** is a small unit of execution inside a program.

For example:

```text
Program
   |
   |---- Thread 1
   |
   |---- Thread 2
   |
   |---- Thread 3
```

Each thread can perform a different task.

---

# 4. Why do we need Threads?

Suppose we have this program:

```java
class Test {
    public static void main(String[] args) {

        System.out.println("Download started");

        // download takes 5 seconds

        System.out.println("Download completed");

        System.out.println("Playing music");
    }
}
```

Execution happens sequentially:

```text
Download
   ↓
Download completed
   ↓
Music
```

The music starts **only after downloading finishes**.

With threads:

```text
Thread 1 → Download
Thread 2 → Music
```

Both can execute concurrently.

---

# 5. Creating a Thread Using `Thread` Class

There are two common ways:

### Method 1

Extend the `Thread` class.

```java
class MyThread extends Thread {

    public void run() {
        System.out.println("Thread is running");
    }
}

public class Main {

    public static void main(String[] args) {

        MyThread t = new MyThread();

        t.start();
    }
}
```

### Output

```text
Thread is running
```

---

# 6. Understand This Code Carefully

```java
class MyThread extends Thread
```

Our class `MyThread` becomes a thread because it extends `Thread`.

Then:

```java
public void run()
```

`run()` contains the **task that the thread should perform**.

Then:

```java
MyThread t = new MyThread();
```

We create the thread object.

Then:

```java
t.start();
```

This starts a **new thread**.

---

# 7. Very Important: `start()` vs `run()`

This is a common interview question.

### Using `start()`

```java
t.start();
```

It creates a **new thread**, and JVM calls `run()`.

```text
main thread
    |
    |---- t.start()
             |
             ↓
        new thread
             |
             ↓
          run()
```

### Using `run()` directly

```java
t.run();
```

It does **not** create a new thread.

It behaves like a normal method call.

```text
main thread
    |
    |---- t.run()
             |
             ↓
        same thread
```

So remember:

```text
start() → creates new thread
run()   → normal method call
```

Here:

```java
obj.display();
```

No new thread is created.

```text

 ↓

```

# 9. Normal Class → Thread

Now change it into a thread:

```java
class Test extends Thread {

    public void run() {
        System.out.println("Hello");
    }
}

public class Main {

    public static void main(String[] args) {

        Test t = new Test();

        t.start();
    }
}
```

Now:

```java
t.start();
```

creates a new thread.

Execution:

```text
             main thread
                 |
              t.start()
                 |
          ┌──────┴──────┐
          ↓             ↓
       main          new thread
                         |
                         ↓
                       run()
```

### Main difference

| Normal class         | Thread                |
| -------------------- | --------------------- |
| Normal method        | `run()` contains task |
| `obj.method()`       | `t.start()`           |
| No new thread        | New thread created    |
| Sequential execution | Concurrent execution  |

# 12. What is `join()`?

`join()` is used when the **main thread wants to wait for another thread to finish**.

Example:

```java
class Test extends Thread {

    public void run() {

        for (int i = 1; i <= 5; i++) {
            System.out.println("Number: " + i);
        }
    }
}

public class Main {

    public static void main(String[] args) {

        Test t = new Test();

        t.start();

        try {
            t.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        System.out.println("Main completed");
    }
}
```

Now output will be:

```text
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
Main completed
```

Why?

Because:

```java
t.join();
```

means:

> **Main thread, wait until `t` finishes.**

---

# 13. `join()` Simple Example

Think of:

```java
t.start();
t.join();

System.out.println("Main completed");
```

as:

```text
Start Thread
     ↓
Thread t is running
     ↓
Main waits ⏸️
     ↓
Thread t finishes
     ↓
Main continues
     ↓
Main completed
```

Without `join()`:

```text
main
 |
 |---- t.start()
 |         |
 |         ↓
 |       Thread
 |
 ↓
Main continues immediately
```

With `join()`:

```text
main
 |
 |---- t.start()
 |         |
 |         ↓
 |       Thread
 |
 |---- t.join()
 |       ⏸️
 |       waits
 |
 ↓
Thread finishes
 |
 ↓
Main continues
```

---

# 14. Why do we use `join()`?

Suppose:

```text
Thread 1 → Download data
Main     → Process data
```

We don't want:

```text
Process data
before
Download completed
```

So:

```java
t.start();
t.join();

processData();
```

means:

```text
Download
   ↓
Download completed
   ↓
Process data
```

# 15. Runnable

Another way to create a thread is using the **`Runnable` interface**.

Example:

```java
class Test implements Runnable {

    public void run() {
        System.out.println("Thread is running");
    }
}

public class Main {

    public static void main(String[] args) {

        Test obj = new Test();

        Thread t = new Thread(obj);

        t.start();
    }
}
```

Notice the difference.

With `Thread`:

```java
class Test extends Thread
```

With `Runnable`:

```java
class Test implements Runnable
```

Then we need:

```java
Thread t = new Thread(obj);
```

and:

```java
t.start();
```

---

# 19. Why Runnable?

Java supports **single inheritance**.

Suppose:

```java
class Test extends Thread
```

Now `Test` cannot extend another class.

For example, this is impossible:

```java
class Test extends Thread, Animal   // ❌
```

But with Runnable:

```java
class Test extends Animal implements Runnable
```

This is possible.

Therefore, `Runnable` is generally more flexible.

# 20. Thread Life Cycle

A thread goes through different states.

```text
             NEW
              |
              | start()
              ↓
           RUNNABLE
          /        \
         /          \
        ↓            ↓
   BLOCKED       WAITING
        \            /
         \          /
          ↓        ↓
           RUNNABLE
              |
              ↓
         TERMINATED
```

Java's official `Thread.State` values are:

```text
NEW
RUNNABLE
BLOCKED
WAITING
TIMED_WAITING
TERMINATED
```

---

## 21. NEW

When the thread object is created:

```java
Thread t = new Thread();
```

The thread is in:

```text
NEW
```

It has not started yet.

---

## 22. RUNNABLE

After:

```java
t.start();
```

the thread becomes eligible to run:

```text
NEW
 ↓
start()
 ↓
RUNNABLE
```

The JVM/thread scheduler decides when it actually executes.

---

## 23. BLOCKED

A thread can become **BLOCKED** when it is waiting to acquire a monitor lock, commonly because another thread holds a `synchronized` lock.

---

## 24. WAITING

A thread can enter `WAITING` when it waits indefinitely for another thread to perform an action.

For example:

```java
t.join();
```

can cause the calling thread to wait for `t`.

---

## 25. TIMED_WAITING

The thread waits for a specified amount of time.

Examples:

```java
Thread.sleep(2000);
```

or:

```java
t.join(2000);
```

---

## 26. TERMINATED

When `run()` finishes:

```text
RUNNABLE
   ↓
run() completed
   ↓
TERMINATED
```

A terminated thread cannot be started again.

# 29. One-Line Interview Answers

**What is multitasking?**

> Executing multiple tasks concurrently.

**What is a thread?**

> A thread is a lightweight unit of execution within a process.

**Why use threads?**

> To perform multiple tasks concurrently and improve responsiveness/utilization.

**What does `start()` do?**

> It starts a new thread and causes the JVM to invoke `run()` on that thread.

**What does `run()` do?**

> It contains the task executed by the thread.

**What does `join()` do?**

> It makes the calling thread wait until the specified thread terminates.

**Why use Runnable?**

> Runnable separates the task from the thread object and allows the class to extend another class.

### Final flow to remember

```text
NORMAL CLASS
    ↓
normal method()
    ↓
same main thread


THREAD CLASS
    ↓
extends Thread
    ↓
override run()
    ↓
start()
    ↓
new thread


RUNNABLE
    ↓
implements Runnable
    ↓
override run()
    ↓
new Thread(runnable)
    ↓
start()
    ↓
new thread


join()
    ↓
calling thread waits
    ↓
other thread finishes
    ↓
calling thread continues
```

The **most important practical distinction** is: `obj.method()` is just a normal method call, while `t.start()` creates a separate thread of execution. `join()` then lets you control the ordering by making the calling thread wait.
