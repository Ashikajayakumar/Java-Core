# 1. What is Multitasking?

**Multitasking** means performing multiple tasks at the same time.

### Real-life example

You are using a computer:

* 🎵 Playing music
* 🌐 Browsing Chrome
* 📄 Editing a document
* 📥 Downloading a file

All these tasks appear to happen simultaneously.

In Java, multitasking is mainly achieved using **threads**.

---

# 2. Types of Multitasking

There are mainly **2 types**:

### 1. Process-based multitasking

Multiple **processes/programs** execute at the same time.

```text
Chrome       → Process
MS Word      → Process
VLC Player   → Process
```

Each process has its own memory.

### 2. Thread-based multitasking

Multiple **threads inside a single program** execute concurrently.

```text
Java Program
     |
     |--- Thread 1 → Download file
     |--- Thread 2 → Play music
     |--- Thread 3 → Display data
```

Java mainly uses **thread-based multitasking**.

---

# 3. What is a Thread?

A **thread** is a small unit of execution inside a program.

```text
Program
   |
   |---- Thread 1
   |---- Thread 2
   |---- Thread 3
```

Each thread can perform a different task.

---

# 4. Life Cycle of a Thread

```text
New → Runnable → Running → Blocked/Waiting/Timed Waiting → Terminated
```

### 1. New

A thread object is created but `start()` has not been called.

```java
Thread t = new Thread();
```

**State:**

```text
New
```

### 2. Runnable

When `start()` is called, the thread becomes ready to execute.

```java
t.start();
```

**State:**

```text
New → Runnable
```

### 3. Running

The CPU scheduler gives CPU time to the thread, and its `run()` method executes.

```text
Runnable → Running
```

### 4. Blocked / Waiting / Timed Waiting

A thread can temporarily stop execution.

Examples:

```java
wait();       // Waiting
sleep(1000);  // Timed Waiting
join();       // Waiting
```

After the waiting condition is completed:

```text
Waiting → Runnable
```

### 5. Terminated

When `run()` finishes, the thread terminates.

```text
Running → Terminated
```

Once terminated, a thread **cannot be restarted**.

# 5. Normal Class vs Thread

## Normal Class

```java
class Test {

    void display() {
        System.out.println("Hello");
    }
}

public class Main {

    public static void main(String[] args) {

        Test obj = new Test();

        obj.display();
    }
}
```

### Output

```text
Hello
```

Here:

```java
obj.display();
```

directly calls the method.

There is **no separate thread created by `Test`**.

---

# 6. Normal Class → Thread

Now we convert the class into a thread.

```java
class Test extends Thread {

    public void run() {
        System.out.println("Hello");
    }
}

public class Main {

    public static void main(String[] args) {

        Test t = new Test();

        t.start();
    }
}
```

### Output

```text
Hello
```

Here:

```java
t.start();
```

starts a new thread, and Java internally calls:

```java
run()
```

### Important

```text
t.start()
   ↓
New Thread is created
   ↓
run() executes
   ↓
Hello
```

Do **not** normally call:

```java
t.run();
```

if your intention is to create a separate thread.

# 7. Without `join()`

Your example:

```java
class A extends Thread {

    int j = 0;

    public void run() {

        for(int i = 0; i < 50; i++) {
            j = i;
        }
    }
}

public class Mainclass {

    public static void main(String[] args) {

        A a1 = new A();

        a1.start();

        System.out.println(a1.j);
    }
}
```

### Possible Output

```text
0
```

But **`0` is not guaranteed**.

You might also get:

```text
5
```

or

```text
20
```

or

```text
49
```

depending on thread scheduling.

Why?

```text
main thread
     |
     |---- a1.start()
     |
     |---- System.out.println(a1.j)
     |
     ↓
   main may print BEFORE
   thread completes
```

The main thread does **not wait** for `a1` to finish.

# 8. What is `join()`?

`join()` makes the **current thread wait until another thread finishes**.

Example:

```java
class Test extends Thread {

    public void run() {

        for (int i = 1; i <= 5; i++) {
            System.out.println("Number: " + i);
        }
    }
}

public class Main {

    public static void main(String[] args) {

        Test t = new Test();

        t.start();

        try {
            t.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        System.out.println("Main completed");
    }
}
```

### Output

```text
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
Main completed
```

### Why?

```text
main
 |
 |---- t.start()
 |       |
 |       ↓
 |     Thread t
 |       |
 |       ↓
 |   Number 1
 |   Number 2
 |   Number 3
 |   Number 4
 |   Number 5
 |
 |---- t.join()
 |       ↓
 |    WAIT
 |
 ↓
Main completed
```

So:

> **`join()` = Wait for the thread to finish.**

# 10. Runnable

Another way to create a thread is using the **`Runnable` interface**.

```java
class Test implements Runnable {

    public void run() {
        System.out.println("Thread is running");
    }
}

public class Main {

    public static void main(String[] args) {

        Test obj = new Test();

        Thread t = new Thread(obj);

        t.start();
    }
}
```

### Output

```text
Thread is running
```

### Flow

```text
Test implements Runnable
          ↓
       run()
          ↓
Thread t = new Thread(obj)
          ↓
       t.start()
          ↓
       run() executes
```

# 11. Runnable + `join()`

```java
class Test implements Runnable {

    public void run() {

        for (int i = 1; i <= 5; i++) {
            System.out.println("Number: " + i);
        }
    }
}

public class Main {

    public static void main(String[] args) {

        Test obj = new Test();

        Thread t = new Thread(obj);

        t.start();

        try {
            t.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        System.out.println("Main completed");
    }
}
```

### Output

```text
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
Main completed
```

### Execution

```text
main thread
    |
    |---- t.start()
    |       |
    |       ↓
    |    Thread t
    |       |
    |       ↓
    |   run()
    |       |
    |       ↓
    |   1 2 3 4 5
    |
    |---- t.join()
    |       |
    |     WAIT
    |       |
    ↓       ↓
Main completed
```
