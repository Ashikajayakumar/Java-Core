# 🔷 What is **Multithreading**?

**Multithreading** is a process of executing **multiple threads simultaneously**.

👉 A **thread** is a **lightweight subprocess** (smallest unit of execution)

---

# 🔷 Why Multithreading?

* Better **CPU utilization**
* Faster execution
* Perform **multiple tasks at same time**
* Used in:

* Games 🎮
* Web servers 🌐
* Background tasks

---

# 🔷 Multitasking Types

## ✅ 1. Process-based (Multiprocessing)

* Separate memory
* Heavyweight
* High cost

---

## ✅ 2. Thread-based (Multithreading)

* Shared memory
* Lightweight
* Fast communication

---

# 🔷 What is a Thread?

👉 A **thread** is an **independent path of execution**

✔ Threads share memory
✔ One thread failure **does not affect others** (mostly)

---

# 🔷 Life Cycle of a Thread

```text
New → Runnable → Running → Waiting/Blocked → Terminated
```

---

# 🔷 Explanation of States

### 🔹 1. **New**

* ✔ Thread created
* ✔ Not started

---

### 🔹 2. **Runnable**

* ✔ Ready to run
* ✔ Waiting for CPU

---

### 🔹 3. **Running**

✔ Thread is executing

---

### 🔹 4. **Blocked / Waiting / Timed Waiting**

* ✔ Temporarily inactive
* ✔ Waiting for resource / time

---

### 🔹 5. **Terminated**

✔ Execution completed

---

# 🔷 Example (Thread Life Cycle)

```java
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread is running");
    }
}

public class Test {
    public static void main(String[] args) {
        MyThread t = new MyThread(); // New state
        t.start(); // Runnable → Running
    }
}
```

---

## ✅ Output

```text
Thread is running
```

# 🔷 Ways to Create Thread

## ✅ 1. By Extending Thread Class

```java
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread using Thread class");
    }
}

public class Test {
    public static void main(String[] args) {
        MyThread t = new MyThread();
        t.start();
    }
}
```

---

## ✅ 2. By Implementing Runnable Interface ⭐ (Recommended)

```java
class MyThread implements Runnable {
    public void run() {
        System.out.println("Thread using Runnable");
    }
}

public class Test {
    public static void main(String[] args) {
        Thread t = new Thread(new MyThread());
        t.start();
    }
}
```

---

# 🔷 `join()` Method

👉 Used to **wait for a thread to finish**

---

## ✅ Example

```java
class MyThread extends Thread {
    public void run() {
        for(int i = 1; i <= 3; i++) {
            System.out.println("Child Thread: " + i);
        }
    }
}

public class Test {
    public static void main(String[] args) throws Exception {
        MyThread t = new MyThread();
        t.start();

        t.join(); // main thread waits

        for(int i = 1; i <= 3; i++) {
            System.out.println("Main Thread: " + i);
        }
    }
}
```

---

## ✅ Output

```text
Child Thread: 1
Child Thread: 2
Child Thread: 3
Main Thread: 1
Main Thread: 2
Main Thread: 3
```

---

## 🔍 Explanation

* `t.start()` → child thread starts
* `t.join()` → main thread waits
* Child finishes first
* Then main executes

---

# 🔷 Without `join()` (Important)

👉 Output may be mixed:

```text
Child Thread: 1
Main Thread: 1
Child Thread: 2
Main Thread: 2
...
```
