# 🔷 Multithreading in Java 

---

# 🔹 1. What is Multithreading?

Multithreading in Java is a process of executing **multiple threads simultaneously**.

👉 A **thread** is the smallest unit of execution (lightweight subprocess).

---

# 🔹 2. Multitasking Types

## 1️⃣ Process-based Multitasking (Multiprocessing)

* Each process has **separate memory**
* Heavyweight
* High communication cost

👉 Example: Running Chrome + VS Code + Spotify

---

## 2️⃣ Thread-based Multitasking (Multithreading)

* Threads share **same memory**
* Lightweight
* Low communication cost

👉 Example: WhatsApp messaging + calling + notifications

---

# 🔹 3. What is a Thread?

A thread is a **lightweight subprocess** that runs independently.

* ✔ Independent execution
* ✔ Shares memory
* ✔ Faster context switching

---

# 🔷 4. Thread Life Cycle (VERY IMPORTANT)

```
NEW → RUNNABLE → RUNNING → WAITING/BLOCKED/TIMED WAITING → TERMINATED
```

---

## 🔹 1️⃣ NEW

Thread is created but not started.

```java
Thread t = new Thread();
```

---

## 🔹 2️⃣ RUNNABLE (Active)

Thread is ready to run.

```java
t.start();
```

---

## 🔹 3️⃣ RUNNING

Thread gets CPU and executes.

---

## 🔹 4️⃣ BLOCKED / WAITING

Thread is waiting for:

* lock
* another thread
* resource

👉 Example:

```java
t.join();
```

---

## 🔹 5️⃣ TIMED WAITING

Waiting for fixed time:

```java
Thread.sleep(2000);
```

---

## 🔹 6️⃣ TERMINATED

Execution completed.

---

# 🔷 5. Thread Creation in Java

There are **2 ways**:

---

## 🔹 1. Extending Thread class

```java
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread running");
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t = new MyThread();
        t.start();
    }
}
```

---

## 🔹 2. Implementing Runnable (BEST PRACTICE)

```java
class MyRunnable implements Runnable {
    public void run() {
        System.out.println("Runnable running");
    }
}

public class Main {
    public static void main(String[] args) {
        Thread t = new Thread(new MyRunnable());
        t.start();
    }
}
```

---

# 🔷 6. Thread Constructors

| Constructor                       | Meaning           |
| --------------------------------- | ----------------- |
| `Thread()`                        | Default thread    |
| `Thread(String name)`             | Named thread      |
| `Thread(Runnable r)`              | Task-based thread |
| `Thread(Runnable r, String name)` | Task + name       |

# 🔷 7. join() Method (IMPORTANT)

## 🔹 What it does:

👉 One thread waits until another thread finishes.

---

## 🔹 Example:

```java
class MyThread extends Thread {
    public void run() {
        for(int i=1; i<=5; i++) {
            System.out.println(i);
            try { Thread.sleep(500); } catch(Exception e) {}
        }
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t = new MyThread();

        t.start();

        try {
            t.join(); // main thread waits here
        } catch(Exception e) {}

        System.out.println("Main thread finished");
    }
}
```

---

## 🔹 Output flow:

```
1
2
3
4
5
Main thread finished
```

# 🔷 8. Thread Execution Cycle Example

### ✔ Scenario:

Two threads running:

```java
class A extends Thread {
    public void run() {
        System.out.println("Thread A running");
    }
}

class B extends Thread {
    public void run() {
        System.out.println("Thread B running");
    }
}

public class Main {
    public static void main(String[] args) {
        A t1 = new A();
        B t2 = new B();

        t1.start();  // NEW → RUNNABLE → RUNNING
        t2.start();
    }
}
```

# 🔷 9. Key Differences (VERY IMPORTANT)

## Thread vs Runnable

| Feature       | Thread         | Runnable             |
| ------------- | -------------- | -------------------- |
| Inheritance   | Extends Thread | Implements interface |
| Flexibility   | Low            | High                 |
| Memory        | More           | Less                 |
| Best practice | ❌              | ✔                    |
