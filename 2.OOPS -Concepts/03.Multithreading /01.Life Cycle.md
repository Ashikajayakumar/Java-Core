# 🔷 Multithreading in Java

## 🧩 What is Multithreading?

Multithreading is a process of executing **multiple threads simultaneously**.

- A **thread** is a lightweight subprocess  
- Smallest unit of execution  

---

## 🔷 What is Multitasking?

Multitasking = executing multiple tasks at the same time.

### ✅ Types:
1. **Process-based multitasking (Multiprocessing)**
2. **Thread-based multitasking (Multithreading)**

---

## 🔷 Process vs Thread

| Feature | Process | Thread |
|--------|--------|--------|
| Memory | Separate | Shared |
| Weight | Heavy | Lightweight |
| Communication | Slow | Fast |
| Example | Browser, Excel | Tasks inside program |

---

## 🔷 Thread-Based Multitasking (Diagram Explanation)

- One program contains multiple tasks
- Each task runs as a **thread**
- CPU executes them using **time sharing**

👉 Example:
- Chatting + Downloading + Notifications

---

## 🔷 What is Thread in Java?

A **thread** is a lightweight subprocess and a **separate path of execution**.

✔ Threads share memory  
✔ Threads are independent  

---

## 🔷 Thread Life Cycle

```

NEW → RUNNABLE → RUNNING → WAITING/BLOCKED → TERMINATED

````

---

### 1️⃣ NEW
Thread is created but not started

```java
Thread t = new Thread();
````

---

### 2️⃣ RUNNABLE

Thread is ready to run

```java
t.start();
```

---

### 3️⃣ RUNNING

Thread gets CPU and executes

---

### 4️⃣ WAITING / BLOCKED

* Waiting for resource or another thread

```java
t.join();          // waiting
synchronized(obj)  // blocked
```

---

### 5️⃣ TIMED WAITING

```java
Thread.sleep(2000);
```

---

### 6️⃣ TERMINATED

Thread execution finished

---

## 🔷 Example Program (Thread Life Cycle)

```java
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread running");

        try {
            Thread.sleep(1000);
        } catch (Exception e) {}

        System.out.println("Thread finished");
    }
}

public class Main {
    public static void main(String[] args) throws Exception {
        MyThread t = new MyThread();

        System.out.println(t.getState()); // NEW

        t.start();
        System.out.println(t.getState()); // RUNNABLE

        Thread.sleep(500);
        System.out.println(t.getState()); // TIMED WAITING

        t.join();
        System.out.println(t.getState()); // TERMINATED
    }
}
```

---

## 🔷 join() Method

👉 Used to make one thread wait for another thread

```java
t1.join();
```

---

### ✅ Example

```java
class MyThread extends Thread {
    public void run() {
        for(int i=1;i<=3;i++) {
            System.out.println(i);
        }
    }
}

public class Main {
    public static void main(String[] args) throws Exception {
        MyThread t1 = new MyThread();

        t1.start();
        t1.join();

        System.out.println("Main thread");
    }
}
```

### Output:

```
1
2
3
Main thread
```

## 🔷 Ways to Create Thread

### 1️⃣ Extending Thread class

```java
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread running");
    }
}
```

---

### 2️⃣ Implementing Runnable (Best Practice)

```java
class MyRunnable implements Runnable {
    public void run() {
        System.out.println("Runnable running");
    }
}
```

---

## 🔷 Thread Constructors

| Constructor                     | Description   |
| ------------------------------- | ------------- |
| Thread()                        | No task       |
| Thread(String name)             | Named thread  |
| Thread(Runnable r)              | Runnable task |
| Thread(Runnable r, String name) | Task + Name   |

---

## 🔷 Example (Best Practice)

```java
class MyRunnable implements Runnable {
    public void run() {
        System.out.println(Thread.currentThread().getName());
    }
}

public class Main {
    public static void main(String[] args) {
        Thread t = new Thread(new MyRunnable(), "Worker-1");
        t.start();
    }
}
```

---

## 🔷 Important Points 🔥

* `start()` → creates new thread
* `run()` → normal method
* Threads share memory
* Exception in one thread does not affect others

---

## 🧠 Quick Revision

* Thread = lightweight process
* Multithreading = parallel execution
* States = NEW → RUNNABLE → WAIT → TERMINATED
* `join()` = wait for thread
* Best practice = Runnable
