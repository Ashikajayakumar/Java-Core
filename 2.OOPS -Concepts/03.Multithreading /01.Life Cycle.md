
# 1. What is Multitasking?

**Multitasking** means performing multiple tasks at the same time.

### Real-life example

You are using a computer:

* 🎵 Playing music
* 🌐 Browsing Chrome
* 📄 Editing a document
* 📥 Downloading a file

All these tasks appear to happen simultaneously.

In Java, multitasking is mainly achieved using **threads**.

---

# 2. Types of Multitasking

There are mainly **2 types**:

### 1. Process-based multitasking

Multiple **processes/programs** execute at the same time.

Example:

```text
Chrome       → Process
MS Word      → Process
VLC Player   → Process
```

Each process has its own memory.

---

### 2. Thread-based multitasking

Multiple **threads inside a single program** execute concurrently.

Example:

```text
Java Program
     |
     |--- Thread 1 → Download file
     |
     |--- Thread 2 → Play music
     |
     |--- Thread 3 → Display data
```

Java mainly uses **thread-based multitasking**.

---

# 3. What is a Thread?

A **thread** is a small unit of execution inside a program.

For example:

```text
Program
   |
   |---- Thread 1
   |
   |---- Thread 2
   |
   |---- Thread 3
```

Each thread can perform a different task.



# 4. Normal Class vs Thread

This is probably the main difference you're asking about.

## Normal class

```java
class Test {

    void display() {
        System.out.println("Hello");
    }
}

public class Main {

    public static void main(String[] args) {

        Test obj = new Test();

        obj.display();
    }
}
```

Here:

```java
obj.display();
```

is a normal method call.

No new thread is created.

Execution:

```text
main
 ↓
display()
 ↓
finish
```

---

# 5. Normal Class → Thread

Now change it into a thread:

```java
class Test extends Thread {

    public void run() {
        System.out.println("Hello");
    }
}

public class Main {

    public static void main(String[] args) {

        Test t = new Test();

        t.start();
    }
}
```

Now:

```java
t.start();
```

creates a new thread.

Execution:

```text
             main thread
                 |
              t.start()
                 |
          ┌──────┴──────┐
          ↓             ↓
       main          new thread
                         |
                         ↓
                       run()
```

### Main difference

| Normal class         | Thread                |
| -------------------- | --------------------- |
| Normal method        | `run()` contains task |
| `obj.method()`       | `t.start()`           |
| No new thread        | New thread created    |
| Sequential execution | Concurrent execution  |

## What happens?

First:

```java
A a1 = new A();
```

An object is created.

```text
a1
 ↓
j = 0
```

Then:

```java
a1.start();
```

This starts a **new thread**.

That new thread executes:

```java
run()
```

and:

```java
for(int i = 0; i < 50; i++)
{
    j = i;
}
```

So `j` is changed:

```text
j = 0
j = 1
j = 2
j = 3

```

---

## But here is the important part

Immediately after:

```java
a1.start();
```

the main thread executes:

```java
System.out.println(a1.j);
```

The **main thread does not automatically wait** for `run()` to finish.

So there are two threads:

```text
                 Program
                    |
          ┌─────────┴─────────┐
          ↓                   ↓
     Main Thread          A Thread
          |                   |
     a1.start()            run()
          |                   |
     print a1.j          j = 0...49
```



The execution becomes:

```text
Main Thread                  A Thread
     |                           |
a1.start() --------------------> run()
     |                           |
a1.join()                       j = 0
     |                           j = 1
     |                           j = 2
     |                           ...
     |                           j = 49
     |                           |
     |<----------------------- thread finishes
     |
print a1.j
     |
    49
```

So with `join()`:

```text
Output = 49
```



# 7. What is `join()`?

`join()` is used when the **main thread wants to wait for another thread to finish**.

Example:

```java
class Test extends Thread {

    public void run() {

        for (int i = 1; i <= 5; i++) {
            System.out.println("Number: " + i);
        }
    }
}

public class Main {

    public static void main(String[] args) {

        Test t = new Test();

        t.start();

        try {
            t.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        System.out.println("Main completed");
    }
}
```

Now output will be:

```text
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
Main completed
```

Why?

Because:

```java
t.join();
```

means:

> **Main thread, wait until `t` finishes.**


8. without runnable
```java
class A extends Thread
{
    public void run()
    {
        System.out.println("Hey Hello...");
    }
}

public class Mainclass
{
    public static void main(String[] args)
    {
        A obj = new A();

        obj.start();
    }
}
```

Let's understand each line.

### 1. `extends Thread`

```java
class A extends Thread
```

This means:

> Class `A` is becoming a thread.

Because `A` extends Java's built-in `Thread` class.

```text
Thread
   ↑
   |
   A
```

So `A` gets thread-related functionality from `Thread`.

---

### 2. `run()`

```java
public void run()
{
    System.out.println("Hey Hello...");
}
```

`run()` contains the **work/task that the thread has to perform**.

Think:

```text
run()
  ↓
Task to execute
```

---

### 3. Create the object

```java
A obj = new A();
```

This creates an object of class `A`.

```text
obj
 ↓
A object
```

At this point, the thread has **not started yet**.

---

### 4. `obj.start()`

```java
obj.start();
```

This is the most important line.

`start()` tells Java:

> "Create/start a new thread and execute the `run()` method on that thread."

Conceptually:

```text
main thread
    |
    | obj.start()
    |
    ↓
new thread
    |
    ↓
run()
    |
    ↓
Hey Hello...
```

---

## Why don't we write `obj.run()`?

You **can** write:

```java
obj.run();
```

But this is different.

### `obj.run()`

```text
main thread
    |
    ↓
obj.run()
    |
    ↓
Hey Hello...
```

No new thread is created.

### `obj.start()`

```text
main thread
    |
    ↓
obj.start()
    |
    ↓
NEW THREAD
    |
    ↓
run()
    |
    ↓
Hey Hello...
```

A very important rule:

> **`start()` creates a new thread; calling `run()` directly is just a normal method call.**

---

## Your image in one flow

```text
class A extends Thread
        ↓
override run()
        ↓
A obj = new A()
        ↓
obj.start()
        ↓
New thread starts
        ↓
run()
        ↓
"Hey Hello..."
```

And if you add:

```java
obj.join();
```

then the **main thread waits for this thread to finish** before continuing.

```text
obj.start()
    ↓
thread starts
    ↓
obj.join()
    ↓
main waits ⏸️
    ↓
run() finishes
    ↓
main continues
```

This is exactly the basic pattern you should remember for **Thread class + `run()` + `start()` + `join()`**.

# 9. Runnable

Another way to create a thread is using the **`Runnable` interface**.

Example:

```java
class Test implements Runnable {

    public void run() {
        System.out.println("Thread is running");
    }
}

public class Main {

    public static void main(String[] args) {

        Test obj = new Test();

        Thread t = new Thread(obj);

        t.start();
    }
}
```

Notice the difference.

With `Thread`:

```java
class Test extends Thread
```

With `Runnable`:

```java
class Test implements Runnable
```

Then we need:

```java
Thread t = new Thread(obj);
```

and:

```java
t.start();
```

# 11. Runnable + `join()`

```java
class Test implements Runnable {

    public void run() {

        for (int i = 1; i <= 5; i++) {
            System.out.println("Number: " + i);
        }
    }
}

public class Main {

    public static void main(String[] args) {

        Test obj = new Test();

        Thread t = new Thread(obj);

        t.start();

        try {
            t.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        System.out.println("Main completed");
    }
}
```

Execution:

```text
main
 |
 |---- Thread t starts
 |         |
 |         ↓
 |      run()
 |         |
 |         ↓
 |      1 2 3 4 5
 |
 |---- join()
 |       waits
 |
 ↓
Main completed
```
