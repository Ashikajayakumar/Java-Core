# 🔷 What is **Multithreading in Java**?

**Multithreading** is a process of executing **multiple threads simultaneously**.

---

## 🧩 What is a Thread?

👉 A **thread** is a **lightweight sub-process**
👉 It is the **smallest unit of execution**

* Runs independently
* Shares memory with other threads

---

# 🔷 What is **Multitasking**?

👉 Executing **multiple tasks at the same time**

---

## 🔷 Types of Multitasking

### 1. **Process-based (Multiprocessing)**

* Each process has **separate memory**
* Heavyweight
* Communication is **slow**

---

### 2. **Thread-based (Multithreading)**

* Threads share **same memory**
* Lightweight
* Communication is **fast**

---

# 🔥 Key Difference

| Feature | Process  | Thread |
| ------- | -------- | ------ |
| Memory  | Separate | Shared |
| Weight  | Heavy    | Light  |
| Speed   | Slow     | Fast   |

---

# 🔷 Thread Life Cycle (States)

```id="tstate"
New → Runnable → Running → Waiting/Blocked → Terminated
```

---

## 🔷 Explanation

### 1. **New**

✔ Thread is created

```java id="ts1"
Thread t = new Thread();
```

---

### 2. **Runnable**

✔ Ready to run

```java id="ts2"
t.start();
```

---

### 3. **Running**

✔ Thread gets CPU and executes

---

### 4. **Blocked / Waiting**

* ✔ Thread pauses temporarily
* ✔ Waiting for resource / time

---

### 5. **Terminated**

✔ Execution finished

---

# 🔷 How to Create Thread in Java?

👉 Two ways:

---

# ✅ 1. By **Extending Thread Class**

```java id="thc1"
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread running");
    }

    public static void main(String[] args) {
        MyThread t = new MyThread();
        t.start();
    }
}
```

---

## ✅ Output

```id="thc2"
Thread running
```

---

## 🔍 Explanation

* `start()` → calls `run()`
* Thread executes independently

---

# ✅ 2. By **Implementing Runnable Interface**

```java id="run1"
class MyThread implements Runnable {
    public void run() {
        System.out.println("Runnable thread running");
    }

    public static void main(String[] args) {
        MyThread obj = new MyThread();
        Thread t = new Thread(obj);
        t.start();
    }
}
```

---

## ✅ Output

```id="run2"
Runnable thread running
```

---

# 🔷 Difference: Thread vs Runnable

| Feature       | Thread Class    | Runnable Interface            |
| ------------- | --------------- | ----------------------------- |
| Inheritance   | Extends Thread  | Implements Runnable           |
| Flexibility   | Less            | More (can extend other class) |
| Best Practice | ❌ Not preferred | ✅ Preferred                   |
