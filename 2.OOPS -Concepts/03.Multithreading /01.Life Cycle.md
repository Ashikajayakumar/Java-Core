
# 1. What is Multitasking?

**Multitasking** means performing multiple tasks at the same time.

### Real-life example

You are using a computer:

* 🎵 Playing music
* 🌐 Browsing Chrome
* 📄 Editing a document
* 📥 Downloading a file

All these tasks appear to happen simultaneously.

In Java, multitasking is mainly achieved using **threads**.

---

# 2. Types of Multitasking

There are mainly **2 types**:

### 1. Process-based multitasking

Multiple **processes/programs** execute at the same time.

Example:

```text
Chrome       → Process
MS Word      → Process
VLC Player   → Process
```

Each process has its own memory.

---

### 2. Thread-based multitasking

Multiple **threads inside a single program** execute concurrently.

Example:

```text
Java Program
     |
     |--- Thread 1 → Download file
     |
     |--- Thread 2 → Play music
     |
     |--- Thread 3 → Display data
```

Java mainly uses **thread-based multitasking**.

---

# 3. What is a Thread?

A **thread** is a small unit of execution inside a program.

For example:

```text
Program
   |
   |---- Thread 1
   |
   |---- Thread 2
   |
   |---- Thread 3
```

Each thread can perform a different task.

# 4. Life Cycle Thread?

```text 
New → Runnable → Running → Blocked/Waiting/Timed Waiting → Terminated
```

### 1. New (Born)

* A thread is created but has not yet started.
* It enters this state when a `Thread` object is instantiated.

```java
Thread t = new Thread();
```

### 2. Runnable (Ready)

* The `start()` method is called.
* The thread is ready to run and is waiting for the CPU scheduler to assign it processor time.

```java
t.start();
```

### 3. Running

* The thread is currently executing its `run()` method.
* The scheduler moves a runnable thread into the running state.

### 4. Blocked / Waiting / Timed Waiting

A running thread may temporarily stop execution due to:

* **Blocked:** Waiting to acquire a lock (monitor).
* **Waiting:** Waiting indefinitely for another thread's action (e.g., `wait()`, `join()`).
* **Timed Waiting:** Waiting for a specified period (e.g., `sleep()`, `join(timeout)`).

After the required event occurs or the timeout expires, the thread returns to the **Runnable** state.

### 5. Terminated (Dead)

* The thread finishes executing the `run()` method or is terminated due to an uncaught exception.
* Once terminated, a thread cannot be restarted.

---

### Life Cycle Diagram

```text
          start()
 New  ----------------> Runnable
                          |
                          | (CPU Scheduler)
                          v
                      Running
                    /    |     \
                   /     |      \
          Blocked  Waiting  Timed Waiting
                   \     |      /
                    \    |     /
                     -----> Runnable
                          |
                          v
                     Terminated
```


# 5. Normal Class vs Thread

This is probably the main difference you're asking about.

## Normal class

```java
class Test {

    void display() {
        System.out.println("Hello");
    }
}

public class Main {

    public static void main(String[] args) {

        Test obj = new Test();

        obj.display();
    }
}
```

Here:

```java
obj.display();
```

# 6. Normal Class → Thread

```java
class Test extends Thread {

    }
}

public class Main {

    public static void main(String[] args) {

        Test t = new Test();

        t.start();
    }
}
```

Now:

```java
t.start();
```

# 8. What is `join()`?

`join()` is used when the **main thread wants to wait for another thread to finish**.

Example:

```java
class Test extends Thread {

    public void run() {

        for (int i = 1; i <= 5; i++) {
            System.out.println("Number: " + i);
        }
    }
}

public class Main {

    public static void main(String[] args) {

        Test t = new Test();

        t.start();

        try {
            t.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        System.out.println("Main completed");
    }
}
```

Now output will be:

```text
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
Main completed
```

# 10. Runnable

Another way to create a thread is using the **`Runnable` interface**.

Example:

```java
class Test implements Runnable {

    public void run() {
        System.out.println("Thread is running");
    }
}

public class Main {

    public static void main(String[] args) {

        Test obj = new Test();

        Thread t = new Thread(obj);

        t.start();
    }
}
```




# 11. Runnable + `join()`

```java
class Test implements Runnable {

    public void run() {

        for (int i = 1; i <= 5; i++) {
            System.out.println("Number: " + i);
        }
    }
}

public class Main {

    public static void main(String[] args) {

        Test obj = new Test();

        Thread t = new Thread(obj);

        t.start();

        try {
            t.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        System.out.println("Main completed");
    }
}
```

Execution:

```text
main
 |
 |---- Thread t starts
 |         |
 |         ↓
 |      run()
 |         |
 |         ↓
 |      1 2 3 4 5
 |
 |---- join()
 |       waits
 |
 ↓
Main completed
```
