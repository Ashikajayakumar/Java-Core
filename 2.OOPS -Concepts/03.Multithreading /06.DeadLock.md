## 🔹 What is Deadlock?

A **deadlock** is a situation in multithreading where:
 
👉 **Two or more threads are waiting for each other forever**
👉 None of them can proceed

✔ Result: Program gets stuck permanently

---

## 🔹 Real-Life Example

### 🪑 Seat + Ticket Example

* Thread A has **Seat** but needs **Ticket**
* Thread B has **Ticket** but needs **Seat**

👉 Both wait for each other forever ❌

---

## 🔹 Simple Analogy

| Thread A        | Thread B        |
| --------------- | --------------- |
| Has Pen ✏️      | Has Paper 📄    |
| Needs Paper     | Needs Pen       |
| Waiting forever | Waiting forever |

👉 This is **Deadlock**

---

# 🔷 Conditions for Deadlock (IMPORTANT)

Deadlock happens when ALL 4 conditions are true:

* 1️⃣ Mutual Exclusion → resource is locked
* 2️⃣ Hold and Wait → holding one resource, waiting for another
* 3️⃣ No Preemption → resource cannot be forcibly taken
* 4️⃣ Circular Wait → circular dependency between threads

# 🔷 Deadlock Example in Java

---

## 🔹 Class One

```java id="one_class"
class One {
    synchronized void methodOne(Two obj) {
        System.out.println("Thread A: methodOne start");

        try { Thread.sleep(100); } catch(Exception e) {}

        obj.methodTwo();
    }

    synchronized void methodTwo() {
        System.out.println("Inside One: methodTwo");
    }
}
```

---

## 🔹 Class Two

```java id="two_class"
class Two {
    synchronized void methodOne(One obj) {
        System.out.println("Thread B: methodOne start");

        try { Thread.sleep(100); } catch(Exception e) {}

        obj.methodTwo();
    }

    synchronized void methodTwo() {
        System.out.println("Inside Two: methodTwo");
    }
}
```

---

## 🔹 Deadlock Thread Class

```java id="deadlock_class"
class Deadlock extends Thread {
    One obj1;
    Two obj2;

    Deadlock(One obj1, Two obj2) {
        this.obj1 = obj1;
        this.obj2 = obj2;
    }

    public void run() {
        obj1.methodOne(obj2);
    }
}
```

---

## 🔹 Main Class

```java id="deadlock_main"
public class Main {
    public static void main(String[] args) {

        One obj1 = new One();
        Two obj2 = new Two();

        Thread t1 = new Deadlock(obj1, obj2);
        Thread t2 = new Deadlock(obj2, obj1);

        t1.start();
        t2.start();
    }
}
```

---

# 🔷 What Happens?

### Thread t1:

👉 Locks `obj1`
👉 Tries to access `obj2`

---

### Thread t2:

👉 Locks `obj2`
👉 Tries to access `obj1`

---

## 🔥 Result:

```text id="deadlock_output"
Thread A waiting for Thread B
Thread B waiting for Thread A
```

👉 Both threads wait forever ❌
👉 Program stuck = DEADLOCK

---

# 🔷 Visual Representation

```text id="deadlock_visual"
Thread A → holds Lock A → waiting for Lock B
Thread B → holds Lock B → waiting for Lock A
```

---

# 🔷 Why Deadlock Happens?

* ✔ Improper synchronization
* ✔ Multiple locks used
* ✔ Wrong order of resource acquisition
* ✔ Nested synchronized blocks

---

# 🔷 How to Avoid Deadlock (IMPORTANT)

* ✔ 1. Avoid nested locks

* ✔ 2. Use same order of locking

* ✔ 3. Use timeout (tryLock in Lock interface)

* ✔ 4. Reduce synchronized block usage
