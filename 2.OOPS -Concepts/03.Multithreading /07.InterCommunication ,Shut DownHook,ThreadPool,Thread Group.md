# 🔷 1. Inter-Thread Communication,Shut DownHook,Thread Pool,Thread Group in Java
 
## 🔹 What is Inter-Thread Communication?  
 
It is a mechanism where **threads communicate with each other** to avoid: 

* ✔ busy waiting 
* ✔ data inconsistency
* ✔ resource conflicts

---

## 🔹 Why is it needed?

👉 When multiple threads share data:

* One thread produces data
* Another consumes it

👉 They must coordinate properly

---

## 🔹 Methods Used

All methods are from **Object class**:

---

### 🔸 `wait()`

👉 Makes thread wait and **releases lock**

```java
obj.wait();
```

✔ Thread goes to **WAITING state**

---

### 🔸 `notify()`

👉 Wakes up **one waiting thread**

```java
obj.notify();
```

---

### 🔸 `notifyAll()`

👉 Wakes up **all waiting threads**

```java
obj.notifyAll();
```

---

## ⚠️ Important Rules

* ✔ Must be used inside **synchronized block/method**
* ✔ Works on **same object lock**
* ✔ `wait()` releases lock, `sleep()` does NOT

---

## 🔹 Simple Flow

```text
Thread 1 → wait()
Thread 2 → notify()
Thread 1 → resumes execution
```

---

## 🔹 Example (Producer-Consumer Concept)

```java
class Shared {
    synchronized void produce() throws Exception {
        System.out.println("Producing...");
        wait(); // waiting
        System.out.println("Resumed");
    }

    synchronized void consume() {
        System.out.println("Consuming...");
        notify(); // wake producer
    }
}
```

# 🔷 2. Shutdown Hook in Java

---

## 🔹 What is Shutdown Hook?

A **Shutdown Hook** is a thread that runs **just before JVM shuts down**.

---

## 🔹 Why it is used?

* ✔ Closing files
* ✔ Saving data
* ✔ Releasing resources
* ✔ Logging

---

## 🔹 Syntax

```java
Runtime.getRuntime().addShutdownHook(new Thread() {
    public void run() {
        System.out.println("Shutdown Hook executed");
    }
});
```

---

## 🔹 Example

```java
public class Main {
    public static void main(String[] args) {

        Runtime.getRuntime().addShutdownHook(new Thread(() -> {
            System.out.println("Cleanup done before shutdown");
        }));

        System.out.println("Program running...");
    }
}
```

# 🔷 3. Thread Group in Java

---

## 🔹 What is Thread Group?

A **Thread Group** is a collection of threads treated as a **single unit**.

---

## 🔹 Why use it?

* ✔ Manage multiple threads easily
* ✔ Control all threads together
* ✔ Monitor thread execution

---

## 🔹 Example

```java
ThreadGroup tg = new ThreadGroup("Group1");

Thread t1 = new Thread(tg, "Thread1");
Thread t2 = new Thread(tg, "Thread2");
```

---

## 🔹 Benefits

* ✔ Bulk operations
* ✔ Easy debugging
* ✔ Organized structure

---

# 🔷 4. Thread Pool in Java

---

## 🔹 What is Thread Pool?

A **Thread Pool** is a collection of **pre-created threads** reused to execute tasks.

---

## 🔹 Why use Thread Pool?

* ✔ Improves performance
* ✔ Reduces thread creation cost
* ✔ Better resource management

---

## 🔹 Types of Thread Pools

---

### 1️⃣ Fixed Thread Pool

✔ Fixed number of threads

```java
Executors.newFixedThreadPool(3);
```

---

### 2️⃣ Cached Thread Pool

✔ Dynamic threads (create as needed)

```java
Executors.newCachedThreadPool();
```

---

### 3️⃣ Single Thread Executor

✔ Only one thread

```java
Executors.newSingleThreadExecutor();
```

---

### 4️⃣ Scheduled Thread Pool

✔ Executes tasks after delay

```java
Executors.newScheduledThreadPool(2);
```

---

## 🔹 Example

```java
import java.util.concurrent.*;

public class Main {
    public static void main(String[] args) {
        ExecutorService ex = Executors.newFixedThreadPool(2);

        ex.execute(() -> System.out.println("Task 1"));
        ex.execute(() -> System.out.println("Task 2"));

        ex.shutdown();
    }
}
```
