# 🧩 What is OOPs?

**OOPs (Object-Oriented Programming System)** is a programming approach based on **objects** and **classes**, used to design software in a **modular, reusable, and real-world way**.

---

# ❓ Why OOPs?
```
✔ **Code Reusability** (reuse code using classes & inheritance)
✔ **Security** (data hiding using encapsulation)
✔ **Flexibility** (use polymorphism)
✔ **Easy Maintenance** (modular structure)
✔ **Real-world modeling** (objects represent real entities)
```

# 🧩 CLASS

A **class** is a **user-defined blueprint** or **prototype** from which **objects are created**.
```
✔ It defines **properties (variables)** and **behaviors (methods)**
✔ Helps create multiple objects without rewriting code
```
---

## 🔑 Parts of Class

1. **Modifiers** → `public`, `default`
2. **Class Name** → Starts with **Capital Letter (convention)**
3. **Superclass** → using `extends` (only **one parent**)
4. **Interfaces** → using `implements` (**multiple allowed**)
5. **Body** → enclosed in `{ }`

---

## ✅ Example

```java
class Student {
    int id;          // property

    void display() { // method
        System.out.println("Student");
    }
}
```

---

# 🧩 OBJECT

An **object** is a **real-world entity** and an **instance of a class**.

✔ Objects interact by **calling methods**

---

## 🔑 Characteristics of Object

### 1. **State**

* Represented by **variables**
* Example: `id`, `name`

### 2. **Behavior**

* Represented by **methods**
* Example: `display()`

### 3. **Identity**

* Unique name/reference of object

---

## ✅ Example

```java
Student s1 = new Student(); // object creation
s1.display();
```

---

# 🧩 METHOD

A **method** is a **block of code** that performs a **specific task**.
```
✔ Can **return value** or **not return anything**
✔ Helps in **code reusability**
```
---

## ✅ Example

```java
void show() {
    System.out.println("Hello");
}
```

---

# 🔷 4 Pillars of OOPs

## 🔹 1. Abstraction

👉 Hides **implementation details** and shows only **essential features**

---

## 🔹 2. Encapsulation

👉 Wrapping **data + methods** into a single unit (class)

---

## 🔹 3. Inheritance

👉 One class **acquires properties** of another class

---

## 🔹 4. Polymorphism

👉 One action, **many forms**

### ✔ Types:

* **Compile-time** → Method Overloading
* **Runtime** → Method Overriding
