## 🔹 What is ArrayList in Java?

### ✅ Definition

* 👉 **ArrayList** is a **class** in Java that implements the `List` interface and is part of the **Java Collections Framework**.
* 👉 It is a **dynamic (resizable) array** used to store a collection of elements.

---

## 🔹 Simple Meaning

👉 ArrayList = **Array + Dynamic size**

Unlike normal arrays:

* Array → fixed size ❌
* ArrayList → grows/shrinks automatically ✔️

## 🔹 Example

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>();

        list.add(10);
        list.add(20);
        list.add(30);

        System.out.println(list);
    }
}
```

👉 Output:

```text
[10, 20, 30]
```

## 🔹 Why ArrayList?

### 1️⃣ Dynamic Size

👉 No need to define size in advance

```java
ArrayList<Integer> list = new ArrayList<>();
```

---

### 2️⃣ Easy Operations

Built-in methods:

* `add()` → insert
* `remove()` → delete
* `get()` → access
* `set()` → update

### 3️⃣ Fast Access (Important 🔥)

👉 Internally uses array → **O(1) access time**

```java
list.get(1); // fast
```

### 4️⃣ Maintains Order

👉 Elements are stored in insertion order

### 5️⃣ Allows Duplicates

```java
list.add(10);
list.add(10);
```

## 🔹 Difference: Array vs ArrayList

| Feature | Array            | ArrayList             |
| ------- | ---------------- | --------------------- |
| Size    | Fixed            | Dynamic               |
| Type    | Primitive/Object | Object only           |
| Methods | Limited          | Many built-in methods |
----

## 🔹 Java Non-Generic vs Generic Collection

# 🔹 1️⃣ Non-Generic Collection

### ✅ Concept

A **non-generic collection** can store **any type of object**.

👉 No type restriction


### 💡 Example

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        ArrayList list = new ArrayList(); // Non-generic

        list.add(10);
        list.add("Java");
        list.add(3.14);

        System.out.println(list);
    }
}
```

👉 Output:

```text
[10, Java, 3.14]
```

### ⚠️ Problems

* No type safety ❌
* Runtime errors possible ❌
* Requires type casting ❌

```java
int num = (int) list.get(1); // Runtime error
```

# 🔹 2️⃣ Generic Collection

### ✅ Concept

A **generic collection** stores **only one specific type of object**.

👉 Type is defined using `< >`

### 💡 Example

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>(); // Generic

        list.add(10);
        list.add(20);
        // list.add("Java"); ❌ Compile-time error

        System.out.println(list);
    }
}
```

👉 Output:

```text
[10, 20]
```

### ✅ Advantages

* Type safety ✔️
* No casting required ✔️
* Compile-time error detection ✔️

---

# 🔹 Key Difference

| Feature     | Non-Generic              | Generic        |
| ----------- | ------------------------ | -------------- |
| Type Safety | ❌ No                     | ✅ Yes          |
| Data Types  | Mixed                    | Single type    |
| Errors      | Runtime                  | Compile-time   |
| Casting     | Required                 | Not required   |
| Usage       | Old Java (before Java 5) | Modern Java ✔️ |
