# 🔷 What is **Polymorphism**?

**Polymorphism** means **“many forms”**.

👉 In Java, it means:
**one method / one action can behave differently in different situations**

---

## ✅ Simple Example

```java
id="poly1"
void add(int a, int b) {}       // 2 parameters
void add(int a, int b, int c) {} // 3 parameters
```

👉 Same method name → different behavior

---

# 🔷 Why Polymorphism?
```
✔ Code reusability
✔ Flexibility
✔ Improves readability
✔ Supports dynamic behavior (runtime decision)
✔ Used in real-world applications
```
---

# 🔷 Types of Polymorphism

## 1. **Compile-Time Polymorphism** (Early Binding)

👉 Achieved using **Method Overloading**

---

# 🔷 Method Overloading

## 🧩 Definition

If a class has **multiple methods with same name but different parameters**, it is called **Method Overloading**.

---

## ✅ Example

```java
id="over1"
class MathUtil {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

---

## ❓ Why not overloading by return type only?

```java
id="over2"
int add(int a, int b) {}
double add(int a, int b) {} // ❌ ERROR
```
```
👉 Because of **ambiguity**
👉 Compiler cannot decide which method to call
```
---

## ❓ Can we overload `main()`?

✔ **Yes**, but:

```java
id="main1"
public static void main(String[] args) { } // JVM calls this

public static void main(int a) { } // overloaded
```

👉 JVM only calls:

```java
id="main2"
main(String[] args)
```

# 🔷 2. **Runtime Polymorphism** (Late Binding)

👉 Achieved using **Method Overriding**

---

# 🔷 Method Overriding

## 🧩 Definition

When a **child class provides its own implementation** of a method already defined in the **parent class**.

---

## ✅ Example

```java
id="overr1"
class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    void sound() {
        System.out.println("Dog barks");
    }
}
```

---

## 🔥 Key Points

* Same method name
* Same parameters
* Inheritance required
* Decision made at **runtime**

---

# 🔷 Covariant Return Type

👉 Method in child class can return **more specific type**

```java
id="cov1"
class A {
    A get() { return this; }
}

class B extends A {
    B get() { return this; } // allowed
}
```

---

# 🔷 `super` Keyword

👉 Refers to **immediate parent class object**

---

## ✅ Uses

* Call parent method
* Access parent variable
* Call parent constructor

---

### Example

```java
id="super1"
class A {
    void show() {
        System.out.println("Parent");
    }
}

class B extends A {
    void show() {
        super.show(); // calls parent method
        System.out.println("Child");
    }
}
```

---

# 🔷 Instance Initializer Block

👉 Block used to **initialize instance variables**

*  Runs **every time object is created**
*  Executes **before constructor**

---

## ✅ Example

```java
id="iib1"
class Test {
    {
        System.out.println("Instance block");
    }

    Test() {
        System.out.println("Constructor");
    }
}
```

---

## ✅ Output

```
Instance block
Constructor
```
