# 🔷 `final`, Casting, and Binding in Java

These are three important Java concepts for **beginner + interview preparation**.

---

# 1. 🔷 `final` Keyword

`final` means **cannot be changed further**.

Java uses `final` with:

```
final
│
├── Variable
├── Method
└── Class

```

---

## 1. `final` Variable

A `final` variable cannot be reassigned after it gets a value.

### Example

```
class Demo {

    public static void main(String[] args) {

        final int MAX = 100;

        System.out.println(MAX);

        // MAX = 200;  // ❌ Error
    }
}

```

### Output

```
100

```

This is not allowed:

```
MAX = 200;

```

because `MAX` is `final`.

### Easy meaning

```
final variable
      ↓
value cannot be reassigned

```

---

## 2. `final` Method

A `final` method **cannot be overridden** by a child class.

### Example

```
class Parent {

    final void display() {
        System.out.println("Parent display");
    }
}

class Child extends Parent {

    // ❌ Cannot override final method
    /*
    void display() {
        System.out.println("Child display");
    }
    */
}

public class Main {

    public static void main(String[] args) {

        Child obj = new Child();

        obj.display();
    }
}

```

### Output

```
Parent display

```

Why?

```
final method
     ↓
Cannot be overridden

```

---

## 3. `final` Class

A `final` class **cannot be inherited**.

### Example

```
final class Parent {

    void display() {
        System.out.println("Parent");
    }
}

/*
class Child extends Parent {  // ❌ Error
}
*/

```

A well-known example is:

```
final class String {
    // ...
}

```

`String` cannot be extended.

### Remember

```
final variable → cannot reassign
final method   → cannot override
final class    → cannot extend

```

---

# 🔷 2. Casting in Java

**Casting** means converting one data type into another.

There are two major types:

```
Casting
│
├── Primitive Casting
│
└── Reference/Object Casting
      │
      ├── Upcasting
      └── Downcasting

```

---

# A. Primitive Casting

## 1. Widening Casting

Converting a **smaller type → larger type**.

Example:

```
int num = 10;

double value = num;

```

Complete example:

```
class Main {

    public static void main(String[] args) {

        int num = 10;

        double value = num;

        System.out.println(num);
        System.out.println(value);
    }
}

```

### Output

```
10
10.0

```

Java automatically performs this conversion.

```
int
 ↓
double

```

Examples:

```
byte → short → int → long → float → double

```

---

# B. Narrowing Casting

Converting a **larger type → smaller type**.

You must explicitly cast.

```
double value = 10.5;

int num = (int) value;

```

Complete example:

```
class Main {

    public static void main(String[] args) {

        double value = 10.5;

        int num = (int) value;

        System.out.println(value);
        System.out.println(num);
    }
}

```

### Output

```
10.5
10

```

The decimal part is lost.

```
10.5
 ↓
(int)
 ↓
10

```

---

# 🔷 Object Casting

Object casting is related to **inheritance**.

Suppose:

```
class Animal {
}

class Dog extends Animal {
}

```

We have:

```
Animal
   ↑
   |
  Dog

```

---

# 1. Upcasting

Converting a child object reference to a parent reference.

```
Dog dog = new Dog();

Animal animal = dog;

```

Or:

```
Animal animal = new Dog();

```

This is **upcasting**.

```
Dog
 ↓
Animal

```

Upcasting is generally automatic.

### Example

```
class Animal {

    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {

    void bark() {
        System.out.println("Dog barks");
    }
}

public class Main {

    public static void main(String[] args) {

        Animal animal = new Dog();

        animal.sound();

        // animal.bark();  // ❌ Not accessible
    }
}

```

The reference type is `Animal`, so only members available through `Animal` can be directly accessed.

---

# 2. Downcasting

Converting a parent reference back to a child reference.

```
Animal animal = new Dog();

Dog dog = (Dog) animal;

```

Complete example:

```
class Animal {

    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {

    void bark() {
        System.out.println("Dog barks");
    }
}

public class Main {

    public static void main(String[] args) {

        Animal animal = new Dog();

        Dog dog = (Dog) animal;

        dog.sound();
        dog.bark();
    }
}

```

### Output

```
Animal sound
Dog barks

```

Here:

```
Animal reference
      ↓
   (Dog)
      ↓
Dog reference

```

### ⚠️ Important

Downcasting is safe only when the actual object really is a `Dog`.

```
Animal animal = new Animal();

Dog dog = (Dog) animal;  // ❌ ClassCastException at runtime

```

# 🔷 3. Binding in Java

**Binding** means connecting a method call to the method implementation that will execute.

There are two important types:

```
Binding
│
├── Early Binding
│
└── Late Binding

```

---

# 1. Early Binding / Static Binding

The method call is resolved at **compile time**.

Common examples:

- Method overloading
- `static` methods
- `private` methods
- `final` methods

### Example: Overloading

```
class Calculator {

    void add(int a, int b) {
        System.out.println("int version");
    }

    void add(double a, double b) {
        System.out.println("double version");
    }
}

public class Main {

    public static void main(String[] args) {

        Calculator obj = new Calculator();

        obj.add(10, 20);
        obj.add(10.5, 20.5);
    }
}

```

### Output

```
int version
double version

```

The compiler determines which overloaded method matches the arguments.

Therefore:

```
Method Overloading
       ↓
Compile Time
       ↓
Early Binding

```

---

# 2. Late Binding / Dynamic Binding

The method implementation is determined at **runtime** based on the actual object.

This happens with **method overriding**.

### Example

```
class Animal {

    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {

    public static void main(String[] args) {

        Animal animal = new Dog();

        animal.sound();
    }
}

```

### Output

```
Dog barks

```

Look carefully:

```
Animal animal = new Dog();

```

Reference type:

```
Animal

```

Actual object:

```
Dog

```

When:

```
animal.sound();

```

Java chooses:

```
Dog's sound()

```

at runtime.

Therefore:

```
Method Overriding
       ↓
Runtime
       ↓
Late Binding

```

# 🔥 Final Comparison

| ConceptMeaningKey Point |                       |                                      |
| ----------------------- | --------------------- | ------------------------------------ |
| `final` variable        | Cannot be reassigned  | Value/reference cannot be reassigned |
| `final` method          | Cannot be overridden  | Child cannot provide override        |
| `final` class           | Cannot be inherited   | No `extends`                         |
| Widening casting        | Smaller → larger      | Usually automatic                    |
| Narrowing casting       | Larger → smaller      | Explicit cast required               |
| Upcasting               | Child → Parent        | Usually automatic                    |
| Downcasting             | Parent → Child        | Explicit cast required               |
| Early binding           | Compile-time decision | Overloading                          |
| Late binding            | Runtime decision      | Overriding                           |
