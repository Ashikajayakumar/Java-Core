

# 🔷 **final Keyword in Java**

The **`final` keyword** is used to **restrict modification**.

👉 It can be applied to:

* **Variable**
* **Method**
* **Class**

# 🔷 1. **Final Variable**

👉 A **final variable** becomes a **constant**

✔ Value **cannot be changed** after initialization

---

### ✅ Example

```java id="f1q9sp"
final int x = 10;
x = 20; // ❌ ERROR
```

---

## 🔸 Blank Final Variable

👉 A **final variable not initialized at declaration**

* Can be initialized **only once**
* Must be initialized in **constructor**

---

### ✅ Example

```java id="l5n3e7"
class Test {
    final int x;

    Test() {
        x = 100; // initialized here
    }
}
```

---

## 🔸 Final Parameter

👉 Parameter declared as **final**

✔ Cannot be modified inside method

```java id="qzqkfj"
void show(final int x) {
    // x = 20; ❌ ERROR
}
```

---

# 🔷 2. **Final Method**

👉 A **final method cannot be overridden**

---

### ✅ Example

```java id="s87p8h"
class A {
    final void show() {
        System.out.println("Final method");
    }
}

class B extends A {
    // void show() {} ❌ ERROR
}
```

---

## ❓ Is final method inherited?

* ✔ **Yes**, it is inherited
* ❌ But **cannot be overridden**

---

# 🔷 3. **Final Class**

👉 A **final class cannot be extended**

---

### ✅ Example

```java id="pnqfxg"
final class A {}

class B extends A {} // ❌ ERROR
```

---

## ❓ Can constructor be final?

❌ **No**

👉 Because constructor is **not inherited**, so no need to restrict it

---

# 🔷 Runtime Polymorphism (Important)

👉 Also called **Dynamic Method Dispatch**

* Method call resolved at **runtime**
* Achieved using **method overriding**

---

# 🔷 Upcasting

👉 **Parent reference → Child object**

```java id="h2z7is"
class A {}
class B extends A {}

A obj = new B(); // upcasting
```

* Safe
* Used in runtime polymorphism

---

# 🔷 Downcasting

👉 **Child reference → Parent object (explicit cast)**

```java id="5q2d3h"
A obj = new B(); 
B b = (B) obj; // downcasting
```

---

## ⚠ Important

* ❌ Wrong downcasting → **Runtime error (ClassCastException)**

```java id="f3t36d"
A obj = new A();
B b = (B) obj; // ❌ runtime error
```

---

# 🔷 Binding in Java

👉 Binding = **linking method call to method body**

---

# 🔷 Types of Binding

## 1. **Static Binding (Early Binding)**

* Happens at **compile time**
* Used for:

* **final methods**
* **static methods**
* **private methods**

---

## 2. **Dynamic Binding (Late Binding)**

* Happens at **runtime**
* Used for:

* **method overriding**

---

# 🔷 Static vs Dynamic Binding

| Feature     | Static Binding         | Dynamic Binding    |
| ----------- | ---------------------- | ------------------ |
| Time        | Compile-time           | Runtime            |
| Method Type | static, final, private | overridden methods |
| Speed       | Faster                 | Slower             |

---

# 🔷 `instanceof` Operator

👉 Used to check **object type**

✔ Returns **true / false**

---

### ✅ Example

```java id="p8sxqs"
class Animal {}
class Dog extends Animal {}

Animal a = new Dog();

System.out.println(a instanceof Dog);    // true
System.out.println(a instanceof Animal); // true
```
