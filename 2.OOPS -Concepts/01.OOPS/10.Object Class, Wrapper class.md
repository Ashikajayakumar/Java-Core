# 🔷 **Object Class in Java**

<img width="1024" height="1536" alt="image" src="https://github.com/user-attachments/assets/ef96571d-4df8-48b3-a762-3d07e799fc28" />


👉 The **`Object` class** is the **parent (superclass) of all classes** in Java.

* Every class **implicitly extends Object**
* It is the **topmost class**

---

## 🔥 Example

```java id="o1x3ka"
class A {}

public class Main {
    public static void main(String[] args) {
        A obj = new A();

        System.out.println(obj.toString()); // from Object class
    }
}
```

---

# 🔷 Object Cloning in Java

👉 **Cloning = creating exact copy of object**

---

## ✅ Requirements

* Implement **`Cloneable` interface**
* Override **`clone()` method**

---

## ✅ Example

```java id="c8z9jt"
class Student implements Cloneable {
    int id;

    public Object clone() throws CloneNotSupportedException {
        return super.clone();
    }
}
```

---

## 🔥 Why use `clone()`?

* ✔ Faster than creating object manually
* ✔ Avoids repetitive code

---

## ⚠ Disadvantages

* ❌ Complex syntax
* ❌ Need to handle exception
* ❌ Must implement `Cloneable`

# 🔷 Autoboxing & Unboxing

## ✅ Autoboxing

👉 Primitive → Object

```java id="a7k2qj"
int x = 10;
Integer obj = x; // autoboxing
```

---

## ✅ Unboxing

👉 Object → Primitive

```java id="p9k4ld"
Integer obj = 20;
int x = obj; // unboxing
```

# 🔷 Difference: Object vs Class

| Feature    | **Object**        | **Class**       |
| ---------- | ----------------- | --------------- |
| Definition | Instance of class | Blueprint       |
| Nature     | Physical entity   | Logical entity  |
| Creation   | `new` keyword     | `class` keyword |
| Memory     | Allocated         | Not allocated   |
| Count      | Many objects      | One class       |

---

## ✅ Example

```java id="n3w8gf"
class Student {} // class

Student s1 = new Student(); // object
Student s2 = new Student();
```
