# 🧩 What is OOPs?

**OOPs (Object-Oriented Programming System)** is a programming approach based on **objects**, where data and behavior are combined.

# ❓ Why OOPs?

* **Code reusability** (write once, use many times)
* **Security** (data hiding using encapsulation)
* **Flexibility & scalability**
* **Easy maintenance**
* Models **real-world problems**

# 🔷 CLASS

A **class** is a **user-defined blueprint** or **prototype** used to create objects.

✔ It defines:

* **Properties (variables)**
* **Behavior (methods)**


## 📌 Class Structure

1. **Modifiers** → `public`, `default`
2. **Class Name** → Starts with **capital letter** (convention)
3. **Superclass** → using **extends** (single inheritance)
4. **Interfaces** → using **implements** (multiple allowed)
5. **Body** → inside `{ }`


## ✅ Example

```java id="xyb4yz"
class Student {
    int id;          // property

    void study() {   // method
        System.out.println("Studying...");
    }
}
```


# 🔷 OBJECT

An **object** is a **real-world entity** created from a class.

```java id="l2mp9l"
Student s = new Student();
```


## 📌 Object Characteristics

### 1. **State**

👉 Represented by **variables (attributes)**
Example: `id`, `name`


### 2. **Behavior**

👉 Represented by **methods**
Example: `study()`



### 3. **Identity**

👉 Unique identity (memory reference)


### 4. **Method**

A **method** is a block of code that:

* Performs a **specific task**
* May or may not **return value**


# 🔷 4 Pillars of OOPs

## 🔸 1. **Abstraction**

👉 Hiding internal details, showing only essentials

Example:

* ATM machine (you don’t know internal working)



## 🔸 2. **Encapsulation**

👉 Wrapping data + methods into one unit

✔ Achieved using:

* **private variables**
* **getters & setters**



## 🔸 3. **Inheritance**

👉 One class **inherits** properties from another

```java id="cm4dj4"
class A {}
class B extends A {}
```


## 🔸 4. **Polymorphism**

👉 One action, many forms

### ✅ Compile-time (Method Overloading)

```java id="46r6bk"
void add(int a, int b) {}
void add(int a, int b, int c) {}
```


### ✅ Runtime (Method Overriding)

```java id="0n33c1"
class A {
    void show() { System.out.println("A"); }
}

class B extends A {
    void show() { System.out.println("B"); }
}
```
