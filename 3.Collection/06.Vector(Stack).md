# 🔹 1️⃣ Vector in Java
<img width="1024" height="1536" alt="image" src="https://github.com/user-attachments/assets/559eeff4-5cda-4425-98ae-dcc1e35ff3e0" />

## ✅ Definition

👉 **Vector** is a **dynamic array (resizable)** that is **thread-safe (synchronized)**.

👉 It is part of the **Java Collections Framework** and extends `AbstractList`.

## 🔹 Key Features (Refined)

* ✔ Dynamic size (grows automatically)

* ✔ Maintains insertion order

* ✔ Allows duplicates & null values

* ✔ Thread-safe (all methods synchronized) 🔥

* ✔ Implements:

* `List`

* `RandomAccess`

* `Cloneable`

* `Serializable`

---

## 🔹 Capacity Concept (Important 🔥)

* 👉 Default capacity = **10**

* 👉 When full:

```text
newCapacity = oldCapacity × 2
```

---

## 🔹 When to Use Vector?

* ✔ Multithreading (thread-safe needed)
* ❌ Avoid in modern apps → slower than ArrayList

# 🔹 🔥 Vector Operations (Added)

## 1️⃣ Adding Elements

```java
v.add(10);
v.add(1, 20); // insert at index
```

---

## 2️⃣ Accessing Elements

```java
v.get(0);
```

---

## 3️⃣ Updating Elements

```java
v.set(0, 50);
```

---

## 4️⃣ Removing Elements

```java
v.remove(0);              // by index
v.remove(Integer.valueOf(20)); // by value
```

---

## 5️⃣ Iterating

```java
for (int num : v) {
    System.out.print(num + " ");
}
```

---

## 🔹 🔥 Complete Vector Program (All Operations)

```java id="vectorfull"
import java.util.*;

public class Main {
    public static void main(String[] args) {

        Vector<Integer> v = new Vector<>();

        // Add
        v.add(10);
        v.add(20);
        v.add(30);
        System.out.println("After add: " + v);

        // Insert
        v.add(1, 15);
        System.out.println("After insert: " + v);

        // Access
        System.out.println("Element at index 2: " + v.get(2));

        // Update
        v.set(2, 25);
        System.out.println("After update: " + v);

        // Remove
        v.remove(3);
        v.remove(Integer.valueOf(15));
        System.out.println("After remove: " + v);

        // Iterate
        System.out.print("Elements: ");
        for (int num : v) {
            System.out.print(num + " ");
        }

        // Size
        System.out.println("\nSize: " + v.size());
    }
}
```

# 🔹 2️⃣ Stack in Java

## ✅ Definition

* 👉 **Stack** is a class that follows **LIFO (Last In First Out)**.
* 👉 It **extends Vector**

## 🔹 Simple Meaning

```text
Push → Add element (top)
Pop → Remove element (top)
Peek → View top element
```

## 🔹 Example (Your Output Explained)

```text
Stack: [1, 2, 3, 4]

Pop order:
4
3
2
1
```

👉 Last element added → removed first ✔️

---

# 🔹 🔥 Stack Operations (Added)

## 1️⃣ Push (Add)

```java
stack.push(10);
```

---

## 2️⃣ Pop (Remove)

```java
stack.pop();
```



## 3️⃣ Peek (Top Element)

```java
stack.peek();
```

## 4️⃣ Search Element

```java
stack.search(10); // returns position
```


## 5️⃣ Check Empty

```java
stack.isEmpty();
```

# 🔹 Vector vs Stack (Important 🔥)

| Feature     | Vector               | Stack                 |
| ----------- | -------------------- | --------------------- |
| Type        | Dynamic Array        | LIFO Data Structure   |
| Inheritance | Extends AbstractList | Extends Vector        |
| Access      | Random access        | Only top element      |
| Methods     | add(), get()         | push(), pop(), peek() |


# 🔹 Complete Stack Program (All Operations)

```java id="stackfull"
import java.util.*;

public class Main {
    public static void main(String[] args) {

        Stack<Integer> stack = new Stack<>();

        // Push
        stack.push(10);
        stack.push(20);
        stack.push(30);

        System.out.println("Stack after push: " + stack);

        // Peek
        System.out.println("Top element: " + stack.peek());

        // Search
        System.out.println("Position of 20: " + stack.search(20));

        // Pop
        System.out.println("Popped: " + stack.pop());

        System.out.println("Stack after pop: " + stack);

        // Check empty
        System.out.println("Is empty? " + stack.isEmpty());

        // Iterate
        System.out.print("Stack elements: ");
        for (int num : stack) {
            System.out.print(num + " ");
        }
    }
}
```

## 🔹 Output

```text
Stack after push: [10, 20, 30]
Top element: 30
Position of 20: 2
Popped: 30
Stack after pop: [10, 20]
Is empty? false
Stack elements: 10 20
```
