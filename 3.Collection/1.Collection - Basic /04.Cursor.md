# 🔷 Cursor in Java Collection

In Java Collections, a **Cursor** is used to **retrieve data (elements) one by one** from a collection object.

👉 It is mainly used for **traversing (iterating)** through collections like List, Set, etc.

## 🔹 What is Cursor?

👉 A **Cursor** is an interface that allows you to:

* Read elements from a collection
* Move through elements sequentially
* (Sometimes) modify or remove elements

👉 Think of it like a **pointer** that moves over elements:

```
[10, 20, 30, 40]
  ↑
 cursor
```

---

## 🔹 Types of Cursors in Java

Java provides **3 types of cursors**:


# 🔷 1️⃣ Enumeration (Legacy Cursor)

👉 Introduced in early versions of Java (mainly for **Vector**, Hashtable)

* ✔ Read-only access
* ❌ Cannot modify elements

### 🔹 Methods with Meaning

* `hasMoreElements()`
 *  👉 Checks **whether more elements are available**
 *  👉 Meaning: **"Is there a next element?"**

* `nextElement()`
*  👉 Returns the **next element** and moves cursor forward
*  👉 Meaning: **"Give me next value"**

---

### **Example:**

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Vector<Integer> v = new Vector<>();
        v.add(10);
        v.add(20);

        Enumeration<Integer> e = v.elements();

        while (e.hasMoreElements()) {
            System.out.println(e.nextElement());
        }
    }
}
```

---

# 🔷 2️⃣ Iterator (Universal Cursor)

👉 Works with all collection classes

* ✔ Read and remove elements
* ❌ Cannot add or update

### 🔹 Methods with Meaning

* `hasNext()`
*  👉 Checks if **next element exists**
* 👉 Meaning: **"Can I move forward?"**

* `next()`
 * 👉 Returns next element and moves cursor forward
 * 👉 Meaning: **"Move forward and give element"**

* `remove()`
 * 👉 Removes the **current element (last returned by next())**
 * 👉 Meaning: **"Delete current element"**

---

### **Example:**

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>();
        list.add(10);
        list.add(20);
        list.add(30);

        Iterator<Integer> it = list.iterator();

        while (it.hasNext()) {
            int val = it.next();
            if (val == 20) {
                it.remove(); // remove element
            }
        }

        System.out.println(list);
    }
}
```

---

# 🔷 3️⃣ ListIterator (Advanced Cursor)

👉 Only for **List implementations** (ArrayList, LinkedList)

* ✔ Read, add, remove, update
* ✔ Traverse **forward & backward**

---

## 🔁 Forward Direction Methods

* `hasNext()`
  * 👉 Checks if next element exists
  * 👉 Meaning: **"Can I move forward?"**

* `next()`
 * 👉 Returns next element and moves forward
 * 👉 Meaning: **"Move forward and give element"**

---

## 🔁 Backward Direction Methods

* `hasPrevious()`
 * 👉 Checks if previous element exists
 * 👉 Meaning: **"Can I move backward?"**

* `previous()`
 * 👉 Returns previous element and moves backward
 * 👉 Meaning: **"Move backward and give element"**

---

## 🔧 Modification Methods

* `add(E e)`
 * 👉 Adds element at current position
 * 👉 Meaning: **"Insert new element here"**

* `set(E e)`
 * 👉 Replaces current element
 * 👉 Meaning: **"Update current value"**

* `remove()`
  * 👉 Removes current element
  * 👉 Meaning: **"Delete current element"**

---

### **Example:**

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>();
        list.add(10);
        list.add(20);

        ListIterator<Integer> li = list.listIterator();

        while (li.hasNext()) {
            int val = li.next();
            if (val == 20) {
                li.set(200); // update element
            }
        }

        System.out.println(list);
    }
}
```
