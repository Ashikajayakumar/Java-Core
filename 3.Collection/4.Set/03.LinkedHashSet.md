## 🔹 What is `LinkedHashSet`?

👉 A `LinkedHashSet` is a collection that:

* ✔ Stores **unique elements** (no duplicates)
* ✔ **Maintains insertion order**
* ✔ Is part of the **`java.util` package**
* ✔ Implements the **`Set` interface**

## 🔹 When to Use?

👉 Use `LinkedHashSet` when:

* ✔ You want **no duplicates**
* ✔ You want to **preserve insertion order**

## 🔹 Create a LinkedHashSet

```java id="lhs1"
import java.util.LinkedHashSet;

LinkedHashSet<String> cars = new LinkedHashSet<>();
```

👉 Now you can use methods like:

* `add()`
* `contains()`
* `remove()`


## 🔹 Add Elements

```java id="lhs2"
import java.util.LinkedHashSet;

public class Main {
  public static void main(String[] args) {

    LinkedHashSet<String> cars = new LinkedHashSet<>();

    cars.add("Volvo");
    cars.add("BMW");
    cars.add("Ford");
    cars.add("BMW");  // Duplicate
    cars.add("Mazda");

    System.out.println(cars);
  }
}
```


## 🔹 Output

```text id="lhs3"
[Volvo, BMW, Ford, Mazda]
```

* ✔ Elements appear in **insertion order**
* ✔ Duplicate `"BMW"` is ignored


## 🔹 Check if Element Exists

```java id="lhs4"
cars.contains("Mazda");
```

✔ Returns `true` or `false`


## 🔹 Remove an Element

```java id="lhs5"
cars.remove("Volvo");
```


## 🔹 Remove All Elements

```java id="lhs6"
cars.clear();
```


## 🔹 LinkedHashSet Size

```java id="lhs7"
cars.size();
```

✔ Counts only **unique elements**


## 🔹 Loop Through LinkedHashSet

```java id="lhs8"
for (String car : cars) {
  System.out.println(car);
}
```

✔ Maintains **insertion order while iterating**


## 🔹 HashSet vs LinkedHashSet

| Feature     | HashSet       | LinkedHashSet     |
| ----------- | ------------- | ----------------- |
| Order       | ❌ No order    | ✔ Insertion order |
| Duplicates  | ❌ Not allowed | ❌ Not allowed     |
| Performance | ⚡ Faster      | ⚡ Slightly slower |
