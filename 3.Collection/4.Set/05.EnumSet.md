## 🔹 What is `EnumSet`?

👉 `EnumSet` is a **specialized Set implementation** used only for:

✔ **Enum (enumeration) types**

## 🔹 Key Features

* ✔ Works only with **enum values**
* ✔ ✔ Stores **unique elements** (like Set)
* ✔ ✔ Very **fast and memory efficient**
* ✔ Maintains **natural order of enum constants**
* ✔ ❌ Does NOT allow null elements
* ✔ ❌ Not synchronized


## 🔹 Why use EnumSet?

👉 Use when:

* ✔ You are working with **enum values**
* ✔ You need **high performance**
* ✔ You want **type safety**



## 🔹 Hierarchy

```text
        Set
         ↑
   AbstractSet
         ↑
      EnumSet
```



## 🔹 Declaration

```java
public abstract class EnumSet<E extends Enum<E>>
    extends AbstractSet<E>
    implements Cloneable, Serializable
```



## 🔹 Important Point

👉 `E extends Enum<E>` means:

✔ EnumSet works **only with enum types**



## 🔹 Example Enum

```java id="es1"
enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}
```



## 🔹 Create EnumSet

```java id="es2"
import java.util.EnumSet;

EnumSet<Day> set = EnumSet.of(Day.MONDAY, Day.WEDNESDAY, Day.FRIDAY);
```



## 🔹 Different Ways to Create EnumSet

### 🔸 1️⃣ Using `of()`

```java id="es3"
EnumSet<Day> set = EnumSet.of(Day.MONDAY, Day.FRIDAY);
```



### 🔸 2️⃣ Using `allOf()`

```java id="es4"
EnumSet<Day> set = EnumSet.allOf(Day.class);
```

✔ Contains all enum values



### 🔸 3️⃣ Using `noneOf()`

```java id="es5"
EnumSet<Day> set = EnumSet.noneOf(Day.class);
```

✔ Empty set



### 🔸 4️⃣ Using `range()`

```java id="es6"
EnumSet<Day> set = EnumSet.range(Day.MONDAY, Day.FRIDAY);
```

✔ From MONDAY → FRIDAY



## 🔹 Basic Operations

### 🔸 Add

```java id="es7"
set.add(Day.SUNDAY);
```


### 🔸 Remove

```java id="es8"
set.remove(Day.MONDAY);
```


### 🔸 Check Element

```java id="es9"
set.contains(Day.FRIDAY);
```


### 🔸 Iterate

```java id="es10"
for (Day d : set) {
    System.out.println(d);
}
```


## 🔹 Example Program

```java id="es11"
import java.util.EnumSet;

enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY
}

public class Main {
    public static void main(String[] args) {

        EnumSet<Day> set = EnumSet.of(Day.MONDAY, Day.WEDNESDAY);

        set.add(Day.FRIDAY);

        System.out.println("EnumSet: " + set);

        for (Day d : set) {
            System.out.println(d);
        }
    }
}
```

## 🔹 EnumSet vs HashSet

| Feature     | EnumSet    | HashSet     |
| ----------- | ---------- | ----------- |
| Data Type   | Only enum  | Any object  |
| Performance | ⚡ Faster   | Slower      |
| Order       | Enum order | No order    |
| Memory      | Efficient  | More memory |
