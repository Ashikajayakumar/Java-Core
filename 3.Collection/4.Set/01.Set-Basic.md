# 🔷 What is `Set`?

👉 A `Set` is an interface in Java that represents a **collection of unique elements**

* ✔ No duplicates allowed
* ✔ Part of **Java Collections Framework**
* ✔ Found in `java.util` package

👉 Think of it like a **mathematical set**:

```text
{10, 20, 30}  ✔ valid  
{10, 20, 10}  ❌ duplicate not allowed
```

# 🔷 Why use `Set`?

👉 Use `Set` when:

✔ You want to **remove duplicates automatically**
✔ You need **fast searching**
✔ Order is **not important** (or use specific type)


# 🔷 Types of Set (4 Main Types)

Based on your diagram + Java hierarchy:


## 1️⃣ HashSet

👉 Most commonly used

* ✔ Uses **hashing (hash table)**
* ✔ No order guaranteed
* ✔ Fast performance → **O(1)**

```java
Set<Integer> set = new HashSet<>();
```
## 2️⃣ LinkedHashSet

👉 Maintains insertion order

* ✔ Internally uses **hash table + linked list**
* ✔ Keeps order in which elements are added

```java
Set<Integer> set = new LinkedHashSet<>();
```

## 3️⃣ TreeSet

👉 Sorted Set

* ✔ Stores elements in **ascending order**
* ✔ Uses **Red-Black Tree**
* ✔ Slower → **O(log n)**

```java
Set<Integer> set = new TreeSet<>();
```

## 4️⃣ EnumSet (Special Type)

👉 Used only for **enum values**

* ✔ Very fast
* ✔ Memory efficient

```java
enum Days { MON, TUE, WED }

EnumSet<Days> set = EnumSet.of(Days.MON, Days.TUE);
```
