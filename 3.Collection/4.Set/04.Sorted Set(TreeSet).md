## 🔹 What is `SortedSet`?

👉 `SortedSet` is an interface that extends `Set`

* ✔ Stores **unique elements**
* ✔ Maintains **elements in sorted order**
* ✔ Sorting is based on:

* Natural ordering (default)
* OR custom comparator

## 🔹 Hierarchy

```text id="ss1"
        Set
         ↑
    SortedSet
         ↑
       TreeSet
```

👉 `TreeSet` is the main implementation of `SortedSet`

# 🔷 Java TreeSet

## 🔹 What is `TreeSet`?

👉 A `TreeSet` is a collection that:

* ✔ Stores **unique elements**
* ✔ Keeps elements **automatically sorted**
* ✔ Part of **`java.util` package**
* ✔ Implements `Set` (and `SortedSet`)

## 🔹 Key Features

* ✔ No duplicates
* ✔ Sorted order (ascending by default)
* ✔ Uses **Red-Black Tree** internally
* ✔ Slower than HashSet (due to sorting)

## 🔹 Create a TreeSet

```java id="ts1"
import java.util.TreeSet;

TreeSet<String> cars = new TreeSet<>();
```


## 🔹 Add Elements

```java id="ts2"
import java.util.TreeSet;

public class Main {
  public static void main(String[] args) {

    TreeSet<String> cars = new TreeSet<>();

    cars.add("Volvo");
    cars.add("BMW");
    cars.add("Ford");
    cars.add("BMW");  // Duplicate
    cars.add("Mazda");

    System.out.println(cars);
  }
}
```

## 🔹 Output

```text id="ts3"
[BMW, Ford, Mazda, Volvo]
```

* ✔ Elements are **automatically sorted**
* ✔ Duplicate `"BMW"` appears only once


## 🔹 Check if Element Exists

```java id="ts4"
cars.contains("Mazda");
```

## 🔹 Remove an Element

```java id="ts5"
cars.remove("Volvo");
```

## 🔹 Remove All Elements

```java id="ts6"
cars.clear();
```

## 🔹 TreeSet Size

```java id="ts7"
cars.size();
```

✔ Counts only **unique elements**


## 🔹 Loop Through TreeSet

```java id="ts8"
for (String i : cars) {
  System.out.println(i);
}
```

✔ Iterates in **sorted order**

## 🔹 Using TreeSet with Numbers

```java id="ts9"
import java.util.TreeSet;

public class Main {
  public static void main(String[] args) {

    TreeSet<Integer> numbers = new TreeSet<>();

    numbers.add(40);
    numbers.add(10);
    numbers.add(30);
    numbers.add(20);

    for (int n : numbers) {
      System.out.println(n);
    }
  }
}
```

## 🔹 Output

```text id="ts10"
10
20
30
40
```

✔ Numbers are sorted from **smallest to largest**

## 🔹 HashSet vs TreeSet

| Feature     | HashSet       | TreeSet              |
| ----------- | ------------- | -------------------- |
| Order       | ❌ No order    | ✔ Sorted (ascending) |
| Duplicates  | ❌ Not allowed | ❌ Not allowed        |
| Performance | ⚡ Faster      | 🐢 Slower (sorting)  |
