## 🔹 What is `HashSet`?

👉 A `HashSet` is a collection where:

* ✔ All elements are **unique** (no duplicates)
* ✔ It is part of the **`java.util` package**
* ✔ It implements the **`Set` interface**


## 🔹 Create a HashSet

```java
import java.util.HashSet;

HashSet<String> cars = new HashSet<String>();
```

👉 Now you can use methods like:

* `add()`
* `contains()`
* `remove()`

## 🔹 Add Elements

```java
import java.util.HashSet;

public class Main {
  public static void main(String[] args) {
    HashSet<String> cars = new HashSet<String>();

    cars.add("Volvo");
    cars.add("BMW");
    cars.add("Ford");
    cars.add("BMW");  // Duplicate
    cars.add("Mazda");

    System.out.println(cars);
  }
}
```

### 🔸 Important Note

👉 Even though `"BMW"` is added twice:

```text
Output: [Volvo, BMW, Ford, Mazda]
```

✔ Duplicate values are **automatically removed**


## 🔹 Check If Element Exists

```java
cars.contains("Mazda");
```

✔ Returns `true` or `false`


## 🔹 Remove Elements

```java
cars.remove("Volvo");
```

👉 Remove all elements:

```java
cars.clear();
```


## 🔹 HashSet Size

```java
cars.size();
```

✔ Counts only **unique elements**


## 🔹 Loop Through HashSet

```java
for (String i : cars) {
  System.out.println(i);
}
```

⚠️ Order is **not guaranteed**

## 🔹 Other Data Types

👉 `HashSet` stores **objects only**

| Primitive | Wrapper Class |
| --------- | ------------- |
| int       | Integer       |
| boolean   | Boolean       |
| char      | Character     |
| double    | Double        |

### 🔸 Example (Integer HashSet)

```java
import java.util.HashSet;

public class Main {
  public static void main(String[] args) {

    HashSet<Integer> numbers = new HashSet<Integer>();

    numbers.add(4);
    numbers.add(7);
    numbers.add(8);

    for (int i = 1; i <= 10; i++) {
      if (numbers.contains(i)) {
        System.out.println(i + " was found in the set.");
      } else {
        System.out.println(i + " was not found in the set.");
      }
    }
  }
}
```

## 🔹 `var` Keyword (Java 10+)

👉 Shorter way to declare:

```java
// Without var
HashSet<String> cars = new HashSet<String>();

// With var
var cars = new HashSet<String>();
```

✔ Compiler automatically detects type

## 🔹 Set vs HashSet (Important Concept)

```java
import java.util.Set;
import java.util.HashSet;

Set<String> cars = new HashSet<>();
```

👉 Explanation:

* `Set` → Interface
* `HashSet` → Implementation

✔ This is called **programming to interface**
