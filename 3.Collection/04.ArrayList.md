# 🔹 What is ArrayList?

<img width="1536" height="1024" alt="image" src="https://github.com/user-attachments/assets/5ca84a9c-d773-43d5-90de-cbca96c02366" />

### ✅ Definition

👉 **ArrayList** is a class in Java that uses a **dynamic array** to store elements.

👉 It is part of the **Java Collections Framework** and implements the `List` interface.

---

## 🔹 Simple Meaning

👉 ArrayList = **Resizable Array (Growable size)**

* No fixed size ❌
* Can add/remove elements anytime ✔️

---

## 🔹 Key Features (Corrected from your notes)

* ✔ Can store **homogeneous (generic)** and **heterogeneous (non-generic)** objects
* ✔ Size is **growable (dynamic)**
* ✔ Default capacity = **10**
* ✔ Stores elements in **continuous memory (like array)**
* ✔ Maintains **insertion order**
* ✔ Allows **duplicates**

✔ Implements:

* `List`
* `RandomAccess`
* `Cloneable`
* `Serializable`


## 🔹 Example

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>();

        list.add(10);
        list.add(20);
        list.add(30);

        System.out.println(list);
    }
}
```

👉 Output:

```text
[10, 20, 30]
```

## 🔹 Why ArrayList?

### 1️⃣ Dynamic Size

👉 No need to define size in advance

```java
ArrayList<Integer> list = new ArrayList<>();
```

---

### 2️⃣ Easy Operations

Built-in methods:

* `add()` → insert
* `remove()` → delete
* `get()` → access
* `set()` → update

### 3️⃣ Fast Access (Important 🔥)

👉 Internally uses array → **O(1) access time**

```java
list.get(1); // fast
```

### 4️⃣ Maintains Order

👉 Elements are stored in insertion order

### 5️⃣ Allows Duplicates

```java
list.add(10);
list.add(10);
```

## 🔹 Difference: Array vs ArrayList

| Feature | Array            | ArrayList             |
| ------- | ---------------- | --------------------- |
| Size    | Fixed            | Dynamic               |
| Type    | Primitive/Object | Object only           |
| Methods | Limited          | Many built-in methods |
----
```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        // 1️⃣ Create ArrayList
        ArrayList<Integer> list = new ArrayList<>();

        // 2️⃣ Add elements
        list.add(10);
        list.add(20);
        list.add(30);
        list.add(40);

        System.out.println("After adding: " + list);

        // 3️⃣ Add element at specific index
        list.add(1, 15);  // insert at index 1
        System.out.println("After inserting at index 1: " + list);

        // 4️⃣ Access element
        int value = list.get(2);
        System.out.println("Element at index 2: " + value);

        // 5️⃣ Update element
        list.set(2, 25);
        System.out.println("After updating index 2: " + list);

        // 6️⃣ Remove element (by index)
        list.remove(3);
        System.out.println("After removing index 3: " + list);

        // 7️⃣ Remove element (by value)
        list.remove(Integer.valueOf(15));
        System.out.println("After removing value 15: " + list);

        // 8️⃣ Print using loop
        System.out.print("Using for loop: ");
        for (int i = 0; i < list.size(); i++) {
            System.out.print(list.get(i) + " ");
        }

        // 9️⃣ Print using for-each
        System.out.print("\nUsing for-each: ");
        for (int num : list) {
            System.out.print(num + " ");
        }

        // 🔟 Check size
        System.out.println("\nSize of list: " + list.size());
    }
}
```
