## 🔹 What is `Map`?

👉 `Map` is part of the **Java Collections Framework**

👉 It stores data in **key-value pairs**

* ✔ Each **key must be unique**
* ✔ **Values can be duplicated**

---

## 🔹 Example

```java id="map1"
Map<Integer, String> map = new HashMap<>();

map.put(1, "A");
map.put(2, "B");
map.put(1, "C"); // replaces value
```

👉 Result:

```text id="map2"
{1=C, 2=B}
```

* ✔ Key `1` is unique → value updated
* ✔ Duplicate keys are **not allowed**

---

# 🔴 Why Map is NOT part of Collection?

👉 This is an **important interview question**

### ✔ Main Reason:

👉 `Collection` stores **only values (single elements)**
👉 `Map` stores **key-value pairs (two elements)**

---

### 🔹 Difference in Structure

| Feature     | Collection      | Map                      |
| ----------- | --------------- | ------------------------ |
| Data stored | Single elements | Key + Value pairs        |
| Example     | `[10, 20, 30]`  | `{1=10, 2=20}`           |
| Interface   | `Collection`    | Separate `Map` interface |

---

👉 So:

✔ `Map` is part of **Collections Framework**
❌ But **does NOT extend `Collection` interface**

---

# 🔷 Why use Map?

👉 Use `Map` when:

✔ You want to **associate one value with another**
✔ Example:

* ID → Name
* Username → Password
* Product → Price

---

# 🔷 Common Map Implementations

## 1️⃣ HashMap

* ✔ Fast (O(1))
* ✔ No order guaranteed
* ✔ Allows one `null` key + multiple `null` values

---

## 2️⃣ LinkedHashMap

* ✔ Maintains **insertion order**
* ✔ Slightly slower than HashMap

---

## 3️⃣ TreeMap

* ✔ Sorted by **keys**
* ✔ Uses **Red-Black Tree**
* ✔ Does NOT allow `null` key

---

## 4️⃣ Hashtable (Legacy)

* ✔ Thread-safe
* ✔ Slower
* ✔ No `null` key/value



# 🔷 Common Map Methods

| Method           | Description             |
| ---------------- | ----------------------- |
| `put(k, v)`      | Add/update key-value    |
| `get(k)`         | Get value by key        |
| `remove(k)`      | Remove entry            |
| `containsKey(k)` | Check key               |
| `keySet()`       | Returns all keys        |
| `values()`       | Returns all values      |
| `entrySet()`     | Returns key-value pairs |


# 🔷 Map vs List vs Set

| Feature         | List  | Set        | Map                 |
| --------------- | ----- | ---------- | ------------------- |
| Duplicates      | ✔ Yes | ❌ No       | Keys ❌, Values ✔    |
| Key-Value pairs | ❌ No  | ❌ No       | ✔ Yes               |
| Order           | ✔ Yes | ❌ (mostly) | ❌ (depends on type) |

# 🔷 Null Handling

| Map Type      | Null Key  | Null Values |
| ------------- | --------- | ----------- |
| HashMap       | ✔ Yes (1) | ✔ Yes       |
| LinkedHashMap | ✔ Yes     | ✔ Yes       |
| TreeMap       | ❌ No      | ✔ Yes       |
| Hashtable     | ❌ No      | ❌ No        |
