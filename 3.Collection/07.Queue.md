
# 📘 1. What is Queue in Java?

## 🔹 Definition

👉 A **Queue** is a linear data structure in Java that follows:

### 👉 **FIFO Principle (First In First Out)**

✔ First element inserted → First element removed

## 🔹 Simple Meaning

👉 Queue works like a **real-world queue (line)**:

* First person in line → served first
* Last person → served last

<img width="1536" height="1024" alt="image" src="https://github.com/user-attachments/assets/458c0a5e-b685-4415-a6d2-45da22f741fb" />


## 🔹 Real-Life Examples

* Ticket counter 🎟️
* Printer queue 🖨️
* CPU scheduling ⏱️


## 🔹 Visual Representation

```text id="queue1"
Front → [10] → [20] → [30] ← Rear
         ↑               ↑
      Remove          Insert
```

# 📘 2. Types of Queue in Java

## 🔷 1️⃣ Simple (Linear) Queue

👉 Follows strict FIFO order

```text id="q2"
Front → A → B → C ← Rear
```

✔ Insert at rear
✔ Remove from front


## 🔷 2️⃣ Circular Queue

👉 Last position connects back to first

```text id="q3"
[1][2][3]
 ↑      ↓
 └──────┘
```

✔ Solves memory wastage problem


## 🔷 3️⃣ Priority Queue

👉 Elements are processed based on priority

✔ Smallest or highest priority comes first

```text id="q4"
Input: 30, 10, 20  
Output: 10, 20, 30
```

## 🔷 4️⃣ Deque (Double Ended Queue)

👉 Insert & remove from both ends

```
Front ← 10 20 30 → Rear
```
✔ Works as Queue + Stack

🔹 5️⃣ Blocking Queue (Advanced - Multithreading)

👉 Used in multithreading

* ✔ Waits when queue is full or empty
* ✔ Example classes:
* ArrayBlockingQueue
* LinkedBlockingQueue

# 📘 3. Why Queue is an Interface?

---

## 🔹 Definition

👉 `Queue` is an **interface** in Java

---

## 🔹 Why Interface?

* ✔ Defines structure (rules)
* ✔ Does NOT provide implementation
* ✔ Allows multiple implementations

---

## 🔹 Queue Hierarchy

```text id="q6"
Iterable
   ↓
Collection
   ↓
Queue (Interface)
   ↓
------------------------
| LinkedList
| PriorityQueue
| ArrayDeque
```

# 📘 4. Why Queue Object Cannot Be Created?

---

## ❌ Wrong

```java
Queue q = new Queue();  // NOT POSSIBLE
```

---

## 🔴 Reason

👉 Because Queue is an **interface**

✔ Interfaces have:

* No constructor
* No object creation
* Only method declarations

---

## 🔹 Example

```java
Queue<Integer> q = new LinkedList<>();   // Correct
```

# 🔷  LinkedList (Queue implementation)

## 🔹 What is LinkedList?

👉 `LinkedList` is a **doubly linked list implementation** in Java
👉 It implements **List + Queue + Deque interfaces**

So it can work as:

* List
* Stack
* Queue


## 🔹 Why use LinkedList as Queue?

* ✔ Dynamic size (no fixed limit)
* ✔ Fast insertion/removal at ends (O(1))
* ✔ Easy FIFO implementation


## 🔹 Theory (How it works)

Each element is stored as a **node**


## 🔹 Queue Methods (Operators)

| Method    | Meaning                           |
| --------- | --------------------------------- |
| offer()   | insert at rear                    |
| add()     | insert (throws exception if fail) |
| poll()    | remove front                      |
| remove()  | remove front (exception if empty) |
| peek()    | view front                        |
| element() | view front (exception if empty)   |


## 🔹 Example Code

```java id="ll2"
import java.util.*;

public class Main {
    public static void main(String[] args) {

        Queue<Integer> q = new LinkedList<>();

        // insert
        q.offer(10);
        q.offer(20);
        q.offer(30);

        System.out.println("Queue: " + q);

        // view front
        System.out.println("Front: " + q.peek());

        // remove
        System.out.println("Removed: " + q.poll());

        System.out.println("After removal: " + q);
    }
}
```

## 🔹 Output

```text
Queue: [10, 20, 30]
Front: 10
Removed: 10
After removal: [20, 30]
```

# 🔷  PriorityQueue

## 🔹 What is PriorityQueue?

👉 A special queue where **elements are processed based on priority**, NOT insertion order.

✔ Default: smallest element has highest priority (min-heap)


## 🔹 Why use PriorityQueue?

* ✔ Task scheduling
* ✔ Dijkstra algorithm
* ✔ Sorting-like behavior automatically

---

## 🔹 Theory (Heap structure)

```text id="pq1"
        10
      /    \
    20      30
```

👉 Always root = smallest element

---

## 🔹 Queue Methods (Operators)

| Method    | Meaning                 |
| --------- | ----------------------- |
| offer()   | insert element          |
| add()     | insert                  |
| poll()    | remove highest priority |
| peek()    | view highest priority   |
| remove()  | delete element          |
| element() | view element            |

---

## 🔹 Example Code

```java id="pq2"
import java.util.*;

public class Main {
    public static void main(String[] args) {

        Queue<Integer> pq = new PriorityQueue<>();

        pq.offer(40);
        pq.offer(10);
        pq.offer(30);
        pq.offer(20);

        System.out.println("PriorityQueue: " + pq);

        System.out.println("Peek: " + pq.peek());

        System.out.println("Removed: " + pq.poll());

        System.out.println("After removal: " + pq);
    }
}
```

## 🔹 Output

```text
PriorityQueue: [10, 20, 30, 40]
Peek: 10
Removed: 10
After removal: [20, 40, 30]
```

# 🔷 ArrayDeque

## 🔹 What is ArrayDeque?

👉 A **resizable circular array-based deque (double-ended queue)**

✔ Works as:

* Queue (FIFO)
* Stack (LIFO)

## 🔹 Why use ArrayDeque?

* ✔ Faster than LinkedList
* ✔ No memory overhead of nodes
* ✔ Best for Queue + Stack operations

## 🔹 Theory

```text id="ad1"
Front → [10, 20, 30] ← Rear
         ↑ circular array
```

## 🔹 Queue Methods (Operators)

| Method        | Meaning      |
| ------------- | ------------ |
| offer()       | add at rear  |
| add()         | insert       |
| poll()        | remove front |
| remove()      | remove front |
| peek()        | view front   |
| addFirst()    | insert front |
| addLast()     | insert rear  |
| removeFirst() | delete front |
| removeLast()  | delete rear  |
| peekFirst()   | view front   |
| peekLast()    | view rear    |


## 🔹 Example Code (Queue usage)

```java id="ad2"
import java.util.*;

public class Main {
    public static void main(String[] args) {

        Queue<Integer> q = new ArrayDeque<>();

        q.offer(10);
        q.offer(20);
        q.offer(30);

        System.out.println("Queue: " + q);

        System.out.println("Front: " + q.peek());

        System.out.println("Removed: " + q.poll());

        System.out.println("After removal: " + q);
    }
}
```


## 🔹 Output

```text
Queue: [10, 20, 30]
Front: 10
Removed: 10
After removal: [20, 30]
```

# 🔷  What is `extends`?

## 🔹 Meaning

👉 `extends` means **inheritance (parent → child relationship)**

✔ One class or interface **inherits properties of another**


## 🔹 Used For

| Type                  | Allowed? |
| --------------------- | -------- |
| Class → Class         | ✔ Yes    |
| Interface → Interface | ✔ Yes    |
| Class → Interface     | ❌ No     |


## 🔹 Example (Class → Class)

```java
class Animal {
    void eat() {
        System.out.println("Eating...");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking...");
    }
}
```

👉 Here:

✔ Dog gets `eat()` from Animal

## 🔹 Example (Interface → Interface)

```java
interface A {
    void show();
}

interface B extends A {
    void display();
}
```

👉 Interface B inherits A

---

## 🔹 Key Idea

👉 `extends` = **IS-A relationship**

Dog **IS-A** Animal ✔️


# 🔷 2️⃣ What is `implements`?

## 🔹 Meaning

👉 `implements` means a class **provides implementation of an interface**

✔ Interface = only declaration
✔ Class = full method body (logic)


## 🔹 Used For

| Type              | Allowed? |
| ----------------- | -------- |
| Class → Interface | ✔ Yes    |


## 🔹 Example

```java
interface Animal {
    void sound();
}

class Dog implements Animal {
    public void sound() {
        System.out.println("Bark");
    }
}
```

👉 Here:

✔ Dog implements behavior of Animal

## 🔹 Key Idea

👉 `implements` = **CAN-DO relationship**

Dog **CAN bark** ✔️

# 🔷  Main Difference Table 🔥

| Feature          | extends                                | implements                                |
| ---------------- | -------------------------------------- | ----------------------------------------- |
| Used for         | Inheritance                            | Interface implementation                  |
| Works on         | Class ↔ Class, Interface ↔ Interface   | Class → Interface                         |
| Method body      | Inherited                              | Must be defined                           |
| Relationship     | IS-A                                   | CAN-DO                                    |
| Multiple support | ❌ Class cannot extend multiple classes | ✔ Class can implement multiple interfaces |



# 🔷  Quick Example (Both Together)

```java
interface A {
    void show();
}

class B {
    void display() {
        System.out.println("Class B");
    }
}

class C extends B implements A {
    public void show() {
        System.out.println("Interface method");
    }
}
```
