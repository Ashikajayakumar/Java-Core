

# 🔷 Difference Between HashMap and Hashtable
<img width="1536" height="1024" alt="image" src="https://github.com/user-attachments/assets/a67043b5-f686-4013-91da-430fe99e8c88" />

👉 Both `HashMap` and `Hashtable`:

* ✔ Store data in **key-value pairs**
* ✔ Use **hashing technique**
* ✔ Ensure **unique keys**


## 🔹 Comparison Table

| No  | HashMap                                                                                            | Hashtable                                  |
| --- | -------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 1️⃣ | ❌ **Non-synchronized** <br> Not thread-safe                                                        | ✔ **Synchronized** <br> Thread-safe        |
| 2️⃣ | ✔ Allows **1 null key** and **multiple null values**                                               | ❌ Does NOT allow any null key or value     |
| 3️⃣ | ✔ Introduced in **JDK 1.2**                                                                        | ✔ **Legacy class** (older)                 |
| 4️⃣ | ⚡ **Faster**                                                                                       | 🐢 **Slower** (due to synchronization)     |
| 5️⃣ | Can be made synchronized manually: <br>`java<br>Map m = Collections.synchronizedMap(hashMap);<br>` | Already synchronized internally            |
| 6️⃣ | Traversed using **Iterator**                                                                       | Traversed using **Iterator + Enumeration** |
| 7️⃣ | Iterator is **fail-fast**                                                                          | Enumeration is **not fail-fast**           |



## 🔹 Important Concepts

### 🔸 Fail-Fast Iterator (HashMap)

👉 If collection is modified during iteration:

```text id="ff1"
Throws ConcurrentModificationException
```

---

### 🔸 Non Fail-Fast Enumeration (Hashtable)

👉 Allows modification during traversal
👉 Does NOT throw exception

---

## 🔹 Simple Example

```java id="hm_ht1"
import java.util.*;

public class Main {
    public static void main(String[] args) {

        HashMap<Integer, String> hm = new HashMap<>();
        hm.put(1, "A");
        hm.put(null, "B"); // Allowed

        Hashtable<Integer, String> ht = new Hashtable<>();
        ht.put(1, "A");
        // ht.put(null, "B"); ❌ Error

        System.out.println("HashMap: " + hm);
        System.out.println("Hashtable: " + ht);
    }
}
```
