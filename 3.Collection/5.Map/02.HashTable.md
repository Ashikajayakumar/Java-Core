## 🔹 What is `Hashtable`?

👉 `Hashtable` is a **legacy class** in Java that:

* ✔ Stores data in **key-value pairs**
* ✔ Implements the **`Map` interface**
* ✔ Extends the **`Dictionary` class**
* ✔ Part of **`java.util` package**


## 🔹 Key Points to Remember

* ✔ Stores data using **hashing (hashCode + equals)**
* ✔ Uses **array of buckets (linked list)**
* ✔ Each bucket stores key-value pairs
* ✔ Keys are **unique**
* ✔ ❌ Does NOT allow `null` key or value
* ✔ ✔ Is **synchronized (thread-safe)**


## 🔹 Why Hashtable?

👉 Used when:

* ✔ You need **thread-safe operations**
* ✔ Multiple threads access data

⚠️ But:

* Slower than `HashMap`
* Mostly replaced by `HashMap` / `ConcurrentHashMap`


## 🔹 Basic Example

```java id="ht1"
import java.util.Hashtable;

public class Main {
    public static void main(String[] args) {

        Hashtable<String, Integer> ht = new Hashtable<>();

        ht.put("One", 1);
        ht.put("Two", 2);
        ht.put("Three", 3);

        System.out.println("Hashtable Elements: " + ht);
    }
}
```


## 🔹 Output

```text id="ht2"
Hashtable Elements: {Two=2, Three=3, One=1}
```

# 🔷 Internal Working (Very Important)

👉 Uses:

* ✔ **Array of buckets**
* ✔ Hash function → decides index

### Steps:

1. Key → `hashCode()`
2. Convert to index
3. Store in bucket

👉 If collision occurs:

✔ Stored in **linked list (same bucket)**
