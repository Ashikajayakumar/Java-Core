## 🔹 What is `LinkedHashMap`?

👉 `LinkedHashMap` is a class that:

* ✔ Stores data in **key-value pairs**
* ✔ Maintains **insertion order**
* ✔ Part of **`java.util` package**
* ✔ Implements the **`Map` interface**
* ✔ Extends **`HashMap`**

---

## 🔹 Key Features

* ✔ Maintains **insertion order**
* ✔ Keys are **unique**
* ✔ ✔ Allows **one null key** and **multiple null values**
* ✔ ❌ Not synchronized (not thread-safe)
* ✔ Combines:

* **Hash table** (for fast access)
* **Linked list** (for order)


## 🔹 Why use LinkedHashMap?

👉 Use when:

* ✔ You need **key-value pairs**
* ✔ You want **predictable iteration order**


## 🔹 Create a LinkedHashMap

```java id="lhm1"
import java.util.LinkedHashMap;

LinkedHashMap<String, String> capitalCities = new LinkedHashMap<>();
```



## 🔹 Add Items

```java id="lhm2"
import java.util.LinkedHashMap;

public class Main {
  public static void main(String[] args) {

    LinkedHashMap<String, String> capitalCities = new LinkedHashMap<>();

    capitalCities.put("England", "London");
    capitalCities.put("India", "New Delhi");
    capitalCities.put("Austria", "Wien");
    capitalCities.put("Norway", "Oslo");
    capitalCities.put("Norway", "Oslo"); // Duplicate key
    capitalCities.put("USA", "Washington DC");

    System.out.println(capitalCities);
  }
}
```


## 🔹 Output

```text id="lhm3"
{England=London, India=New Delhi, Austria=Wien, Norway=Oslo, USA=Washington DC}
```

* ✔ Maintains **insertion order**
* ✔ Duplicate key (`Norway`) is **replaced (not added twice)**


## 🔹 Access an Item

```java id="lhm4"
capitalCities.get("England");
```



## 🔹 Remove an Item

```java id="lhm5"
capitalCities.remove("England");
```

👉 Remove all:

```java id="lhm6"
capitalCities.clear();
```


## 🔹 LinkedHashMap Size

```java id="lhm7"
capitalCities.size();
```

✔ Counts only **unique keys**


## 🔹 Loop Through LinkedHashMap

### 🔸 Keys

```java id="lhm8"
for (String key : capitalCities.keySet()) {
  System.out.println(key);
}
```


### 🔸 Values

```java id="lhm9"
for (String value : capitalCities.values()) {
  System.out.println(value);
}
```


### 🔸 Keys + Values

```java id="lhm10"
for (String key : capitalCities.keySet()) {
  System.out.println("Key: " + key + ", Value: " + capitalCities.get(key));
}
```

## 🔹 HashMap vs LinkedHashMap

| Feature     | HashMap    | LinkedHashMap     |
| ----------- | ---------- | ----------------- |
| Order       | ❌ No order | ✔ Insertion order |
| Performance | ⚡ Faster   | ⚡ Slightly slower |
| Nulls       | ✔ Allowed  | ✔ Allowed         |
| Keys        | Unique     | Unique            |

👉 Tip:

* Use `HashMap` → when **speed matters**
* Use `LinkedHashMap` → when **order matters**


## 🔹 `var` Keyword (Java 10+)

```java id="lhm11"
// Without var
LinkedHashMap<String, String> map = new LinkedHashMap<>();

// With var
var map = new LinkedHashMap<String, String>();
```


## 🔹 Map Interface Usage

```java id="lhm12"
import java.util.Map;
import java.util.LinkedHashMap;

Map<String, String> capitalCities = new LinkedHashMap<>();
```

👉 `Map` = Interface
👉 `LinkedHashMap` = Implementation

✔ Provides flexibility to change implementation later

---

## 🔹 Internal Working (Important)

👉 Uses:

* ✔ **HashMap structure** (for fast lookup)
* ✔ + **Doubly linked list** (to maintain order)
