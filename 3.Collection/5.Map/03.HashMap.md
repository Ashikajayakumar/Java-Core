## 🔹 What is `HashMap`?

👉 `HashMap` is a class that implements the **Map interface**

👉 It stores data in **key-value pairs**

* ✔ Keys must be **unique**
* ✔ Values can be **duplicated**
* ✔ If duplicate key is added → **value is replaced**


## 🔹 Key Features

* ✔ Stores data as **(key → value)**
* ✔ **No indexing** (uses keys instead)
* ✔ **Fast operations** → O(1) average
* ✔ Allows:

* ✔ One `null` key
* ✔ Multiple `null` values

* ✔ ❌ Not synchronized
* ✔ ❌ Does NOT maintain order


## 🔹 Internal Details (Important)

👉 Default capacity = **16**
👉 Load factor = **0.75**

* ✔ Uses **hashing mechanism**
* ✔ Converts key → hash → bucket


## 🔹 Create a HashMap

```java id="hm1"
import java.util.HashMap;

HashMap<String, String> map = new HashMap<>();
```

👉 Generic format:

```java id="hm2"
HashMap<K, V> map = new HashMap<>();
```

* `K` → Key type
* `V` → Value type



## 🔹 Add Elements

```java id="hm3"
map.put("India", "New Delhi");
map.put("USA", "Washington DC");
map.put("UK", "London");
```

👉 Duplicate key:

```java id="hm4"
map.put("USA", "New York"); // replaces value
```

## 🔹 Access Elements

```java id="hm5"
map.get("India");
```

## 🔹 Remove Elements

```java id="hm6"
map.remove("USA");
```

👉 Remove all:

```java id="hm7"
map.clear();
```


## 🔹 Size

```java id="hm8"
map.size();
```

✔ Counts only **unique keys**


## 🔹 Loop Through HashMap

### ✔ Keys only

```java id="hm9"
for (String key : map.keySet()) {
    System.out.println(key);
}
```

### ✔ Values only

```java id="hm10"
for (String value : map.values()) {
    System.out.println(value);
}
```

### ✔ Keys + Values

```java id="hm11"
for (String key : map.keySet()) {
    System.out.println(key + " : " + map.get(key));
}
```

# 🔹 Example Code (Complete)

```java id="hm12"
import java.util.HashMap;

public class Main {
    public static void main(String[] args) {

        // Create HashMap
        HashMap<String, String> capitalCities = new HashMap<>();

        // Add elements
        capitalCities.put("England", "London");
        capitalCities.put("India", "New Delhi");
        capitalCities.put("Austria", "Wien");
        capitalCities.put("Norway", "Oslo");
        capitalCities.put("Norway", "Bergen"); // Duplicate key (replaced)
        capitalCities.put("USA", "Washington DC");

        // Print map
        System.out.println("Map: " + capitalCities);

        // Access value
        System.out.println("Capital of India: " + capitalCities.get("India"));

        // Remove element
        capitalCities.remove("Austria");

        System.out.println("After removal: " + capitalCities);

        // Size
        System.out.println("Size: " + capitalCities.size());

        // Loop (key + value)
        System.out.println("All entries:");
        for (String key : capitalCities.keySet()) {
            System.out.println(key + " -> " + capitalCities.get(key));
        }
    }
}
```
