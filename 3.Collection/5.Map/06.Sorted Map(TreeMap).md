## 🔹 What is `SortedMap`?

👉 `SortedMap` is an **interface** in Java that:

* ✔ Extends the **Map interface**
* ✔ Stores **key-value pairs in sorted order (by keys)**



## 🔹 Hierarchy

```text
        Map
         ↑
     SortedMap
         ↑
   NavigableMap
         ↑
      TreeMap
```



## 🔹 Key Features of SortedMap

* ✔ Keys are **automatically sorted**
* ✔ Sorting is based on:

* Natural order (ascending) OR
* Custom comparator

* ✔ Does NOT allow duplicate keys
* ✔ Provides methods like:

* `firstKey()`
* `lastKey()`
* `headMap()`
* `tailMap()`



## 🔹 Why SortedMap?

👉 Use when:

* ✔ You need **sorted data**
* ✔ You want **range operations**



# 🔷 Java TreeMap Class

## 🔹 What is `TreeMap`?

👉 `TreeMap` is:

* ✔ A **Red-Black Tree based implementation**
* ✔ Stores **key-value pairs in sorted order**
* ✔ Implements **NavigableMap**
* ✔ Extends **AbstractMap**



## 🔹 Key Points

* ✔ Stores values based on **keys**
* ✔ Keys are **unique**
* ✔ Maintains **ascending order**
* ✔ ❌ No null key
* ✔ ✔ Allows multiple null values
* ✔ ❌ Not synchronized



## 🔹 Internal Working

👉 Uses:

✔ **Red-Black Tree (Self-balancing BST)**

👉 Ensures:

* ✔ Sorted order
* ✔ O(log n) operations



## 🔹 Create TreeMap

```java
import java.util.TreeMap;

TreeMap<String, String> capitalCities = new TreeMap<>();
```

## 🔹 Add Items

```java
import java.util.TreeMap;

public class Main {
  public static void main(String[] args) {

    TreeMap<String, String> capitalCities = new TreeMap<>();

    capitalCities.put("England", "London");
    capitalCities.put("India", "New Delhi");
    capitalCities.put("Austria", "Wien");
    capitalCities.put("Norway", "Oslo");
    capitalCities.put("Norway", "Oslo"); // Duplicate
    capitalCities.put("USA", "Washington DC");

    System.out.println(capitalCities);
  }
}
```


## 🔹 Output

```text
{Austria=Wien, England=London, India=New Delhi, Norway=Oslo, USA=Washington DC}
```

* ✔ Keys are **sorted automatically**
* ✔ Duplicate keys are **replaced**



## 🔹 Access Item

```java
capitalCities.get("England");
```

## 🔹 Remove Item

```java
capitalCities.remove("England");
```

👉 Remove all:

```java
capitalCities.clear();
```

## 🔹 Size

```java
capitalCities.size();
```

✔ Counts only **unique keys**


## 🔹 Traversal

### 🔸 Keys

```java
for (String key : capitalCities.keySet()) {
  System.out.println(key);
}
```

### 🔸 Values

```java
for (String value : capitalCities.values()) {
  System.out.println(value);
}
```

### 🔸 Keys + Values

```java
for (String key : capitalCities.keySet()) {
  System.out.println("Key: " + key + " Value: " + capitalCities.get(key));
}
```


## 🔹 TreeMap vs HashMap

| Feature     | HashMap       | TreeMap             |
| ----------- | ------------- | ------------------- |
| Order       | ❌ No order    | ✔ Sorted (by keys)  |
| Null Key    | ✔ One allowed | ❌ Not allowed       |
| Performance | ⚡ Faster      | 🐢 Slower (sorting) |
| Structure   | Hash Table    | Red-Black Tree      |

## 🔹 `var` Keyword

```java
// Without var
TreeMap<String, String> map = new TreeMap<>();

// With var
var map = new TreeMap<String, String>();
```


## 🔹 Map Interface Usage

```java
import java.util.Map;
import java.util.TreeMap;

Map<String, String> capitalCities = new TreeMap<>();
```

✔ Interface-based coding (flexible)
