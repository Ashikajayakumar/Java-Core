# 🔷 1. What is List Interface in Java?

## 🔹 Definition

👉 The **List interface** is part of the Java Collections Framework that represents an **ordered collection of elements**.

## 🔹 Key Characteristics

* ✔ Maintains **insertion order**
* ✔ Allows **duplicate elements**
* ✔ Allows **null values**
* ✔ Supports **index-based access**


## 🔹 Important Point

* 👉 `List` is an **interface**, so:

* ❌ Cannot create object directly

* ✔ Must use implementing classes:

* `ArrayList`
* `LinkedList`
* `Vector`
* `Stack`



# 🔷 2. Simple Meaning

👉 List = **Ordered + Indexed + Duplicates Allowed**

# 🔷 3. Example

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> list = new ArrayList<>();

        list.add(10);
        list.add(20);
        list.add(10); // duplicate allowed

        System.out.println(list);
    }
}
```

✔ Output:

```text
[10, 20, 10]
```



# 🔷 4. Common List Methods

| Method                  | Description    |
| ----------------------- | -------------- |
| `add()`                 | Adds element   |
| `get(int index)`        | Access element |
| `set(int index, value)` | Update element |
| `remove(int index)`     | Delete element |
| `size()`                | Returns size   |


# 🔷 5. List vs Array

| Feature     | Array           | List                  |
| ----------- | --------------- | --------------------- |
| Size        | Fixed           | Dynamic               |
| Flexibility | Less            | More                  |
| Framework   | Not part of JCF | Part of JCF           |
| Methods     | Limited         | Many built-in methods |


# 🔷 6. List Hierarchy

```text

```


# 🔷 7. Implementing Classes

## 🔹 1️⃣ ArrayList

👉 Dynamic array

* ✔ Fast access (O(1))
* ❌ Slow insertion/deletion (middle)

## 🔹 2️⃣ LinkedList

👉 Doubly linked list

* ✔ Fast insertion/deletion
* ❌ Slow access (O(n))

## 🔹 3️⃣ Vector

👉 Thread-safe version of ArrayList

⚠️ Less used (legacy)

## 🔹 4️⃣ Stack

👉 LIFO (Last In First Out)

# 🔷 8. ListIterator (Important 🔥)

👉 Used to traverse list:

* ✔ Forward
* ✔ Backward

```java
ListIterator<Integer> it = list.listIterator();
```

# 🔷 9. Why Use List?

Use List when:

* ✔ Order matters
* ✔ Duplicates allowed
* ✔ Need index-based access
