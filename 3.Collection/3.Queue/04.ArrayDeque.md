## 🔹 What is ArrayDeque?

👉 `ArrayDeque` is a **resizable circular array-based deque (double-ended queue)**

✔ It allows insertion and deletion from **both ends**

✔ Works as:

* Queue (FIFO)
* Stack (LIFO)


## 🔹 Internal Working 

👉 Uses a **circular array**, NOT a linked list

👉 Two pointers are maintained:

* `front` (head)
* `rear` (tail)

👉 When end of array is reached:

* It **wraps around** (circular behavior)


## 🔹 Theory

```text id="j3a7l9"
Front → [10, 20, 30] ← Rear
         ↑ circular array
```

👉 Example of circular nature:

* ✔ No shifting of elements
* ✔ Efficient use of space


## 🔹 Why use ArrayDeque?

* ✔ Faster than `LinkedList`
* ✔ No extra memory (no node pointers)
* ✔ Better cache performance
* ✔ O(1) insertion/removal at both ends

⚠️ Limitation:

* ❌ No `null` elements allowed

---

## 🔹 Time Complexity

| Operation        | Time        |
| ---------------- | ----------- |
| add/remove front | O(1)        |
| add/remove rear  | O(1)        |
| resize           | O(n) (rare) |

---

## 🔹 Queue Methods (Operators)

| Method          | Meaning         |
| --------------- | --------------- |
| `offer()`       | add at rear     |
| `add()`         | insert          |
| `poll()`        | remove front    |
| `remove()`      | remove front    |
| `peek()`        | view front      |
| `addFirst()`    | insert at front |
| `addLast()`     | insert at rear  |
| `removeFirst()` | delete front    |
| `removeLast()`  | delete rear     |
| `peekFirst()`   | view front      |
| `peekLast()`    | view rear       |

👉 🔥 Key Idea:

* `offer/poll/peek` → **safe methods**
* `add/remove` → **exception methods**

## 🔹 Example Code (Queue usage)

```java id="x8z4kb"
import java.util.*;

public class Main {
    public static void main(String[] args) {

        Queue<Integer> q = new ArrayDeque<>();

        // 🔸 Insert elements (FIFO)
        q.offer(10);
        q.offer(20);
        q.offer(30);

        System.out.println("Queue: " + q);

        // 🔸 View front
        System.out.println("Front: " + q.peek());

        // 🔸 Remove front
        System.out.println("Removed: " + q.poll());

        System.out.println("After removal: " + q);
    }
}
```

---

## 🔹 Output

```text id="f4j6na"
Queue: [10, 20, 30]
Front: 10
Removed: 10
After removal: [20, 30]
```

## 🔹 Example Code (Deque usage — BOTH ENDS)

```java id="n2r9hz"
import java.util.*;

public class Main {
    public static void main(String[] args) {

        Deque<Integer> dq = new ArrayDeque<>();

        // 🔸 Add elements at both ends
        dq.addFirst(20);
        dq.addLast(30);
        dq.addFirst(10);

        System.out.println("Deque: " + dq);

        // 🔸 Access elements
        System.out.println("Front: " + dq.peekFirst());
        System.out.println("Rear: " + dq.peekLast());

        // 🔸 Remove elements
        dq.removeFirst();
        dq.removeLast();

        System.out.println("After removals: " + dq);
    }
}
```

---

## 🔹 Output

```text id="m5y3qv"
Deque: [10, 20, 30]
Front: 10
Rear: 30
After removals: [20]
```

## 🔹 Stack Behavior using ArrayDeque

👉 Recommended instead of `Stack` class

```java id="v3k8qp"
Deque<Integer> stack = new ArrayDeque<>();

stack.push(10);
stack.push(20);
stack.push(30);

System.out.println(stack.pop()); // 30
```

✔ Works as **LIFO**

## 🔹 ArrayDeque vs LinkedList (Important)

| Feature        | ArrayDeque     | LinkedList         |
| -------------- | -------------- | ------------------ |
| Structure      | Circular Array | Doubly Linked List |
| Speed          | Faster         | Slower             |
| Memory         | Less           | More (nodes)       |
| Cache Friendly | Yes            | No                 |
| Null allowed   | ❌ No           | ✔ Yes              |
