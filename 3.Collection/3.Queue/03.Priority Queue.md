

# 🔷 PriorityQueue in Java 

## 🔹 What is `PriorityQueue`?

👉 A `PriorityQueue` is a queue where:

* ✔ Elements are ordered by **priority**, not insertion order
* ✔ Internally implemented using a **binary heap**

## 🔹 Default Behavior (Min-Heap)

👉 By default, Java uses a **min-heap**

* ✔ Smallest element = **highest priority**
* ✔ Always available at the **root**


## 🔹 Heap Structure (Important Concept)

Example after inserting:

```
Insert: 40, 10, 30, 20
```

Heap becomes:

```
        10
      /    \
    20      30
   /
 40
```

👉 Rules:

* Parent ≤ Children
* Tree is **complete binary tree**

## 🔹 How Insertion Works (Heapify Up)

Insert `20` step-by-step:

```
Step 1: Add at last
        10
      /    \
    20      30
   /
 40
```

👉 Compare with parent → swap if smaller
👉 Maintain heap property


## 🔹 How Removal Works (Heapify Down)

👉 `poll()` removes root (smallest)

Steps:

1. Remove root (10)
2. Move last element (40) to root
3. Heapify down (swap with smaller child)

```
Before:
        10
      /    \
    20      30
   /
 40

After removing 10:
        40
      /    \
    20      30
```

Fix heap:

```
        20
      /    \
    40      30
```


## 🔹 Important Methods (Deep Understanding)

| Method      | Behavior                                  |
| ----------- | ----------------------------------------- |
| `offer(e)`  | Inserts element (safe)                    |
| `add(e)`    | Same as offer (throws exception if fails) |
| `peek()`    | Returns smallest element (no removal)     |
| `poll()`    | Removes smallest element                  |
| `remove()`  | Removes element (exception if empty)      |
| `element()` | Returns head (exception if empty)         |


## 🔹 Key Observation ⚠️

```java
System.out.println(pq);
```

👉 Output:

```
[10, 20, 30, 40]
```

⚠️ This is **NOT guaranteed sorted order**

👉 It is just **heap representation**

## 🔹 Correct Way to Get Sorted Order

👉 Use repeated `poll()`

```java
while(!pq.isEmpty()) {
    System.out.print(pq.poll() + " ");
}
```

✔ Output:

```
10 20 30 40
```

---

## 🔹 Time Complexity

| Operation        | Time     |
| ---------------- | -------- |
| Insert (`offer`) | O(log n) |
| Remove (`poll`)  | O(log n) |
| Peek             | O(1)     |

## 🔹 Custom Priority (Max Heap)

* 👉 By default → Min Heap
* 👉 For Max Heap:

```java
PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder());
```

✔ Now:

* Largest element = highest priority

## 🔹 Example (Max Heap)

```java
pq.offer(10);
pq.offer(50);
pq.offer(20);

System.out.println(pq.poll());
```

✔ Output:

```
50
```

## 🔹 Detailed Example Code

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        // Create PriorityQueue (Min Heap by default)
        Queue<Integer> pq = new PriorityQueue<>();

        // 🔸 Insertion
        pq.offer(40);
        pq.offer(10);
        pq.offer(30);
        pq.offer(20);

        System.out.println("After insertion: " + pq);

        // 🔸 Peek (view smallest element)
        System.out.println("Peek (smallest): " + pq.peek());

        // 🔸 Remove highest priority (smallest element)
        int removed = pq.poll();
        System.out.println("Removed element: " + removed);

        System.out.println("After removal: " + pq);

        // 🔸 Insert more elements
        pq.offer(5);
        pq.offer(50);

        System.out.println("After adding more elements: " + pq);

        // 🔸 Traversing using iterator
        System.out.print("Using Iterator: ");
        Iterator<Integer> it = pq.iterator();
        while(it.hasNext()) {
            System.out.print(it.next() + " ");
        }

        System.out.println();

        // 🔸 Sorted order (IMPORTANT)
        System.out.print("Sorted order (using poll): ");
        while(!pq.isEmpty()) {
            System.out.print(pq.poll() + " ");
        }
    }
}
```
