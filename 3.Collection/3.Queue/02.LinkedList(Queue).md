## 🔹 What is `LinkedList`?

👉 In Java, `LinkedList` is a **doubly linked list implementation**
👉 It implements:

* `List`
* `Queue`
* `Deque`

✔ That means it can behave like:

* List (ordered collection)
* Queue (FIFO)
* Stack (LIFO, via Deque methods)

---

## 🔹 Internal Working (Important)

👉 Each element is stored in a **node** containing:

* Data
* Reference to **previous node**
* Reference to **next node**

✔ This is why it is called a **doubly linked list**


## 🔹 Why use `LinkedList` as Queue?

✔ Dynamic size (no resizing like arrays)
✔ Fast insertion/removal at **head and tail → O(1)**
✔ No shifting of elements (unlike ArrayList)

⚠️ But:

* ❌ More memory (extra pointers)
* ❌ Slower random access (no indexing like array)

---

## 🔹 Queue Methods (Very Important Difference)

| Method      | Behavior if Queue is Empty |
| ----------- | -------------------------- |
| `offer()`   | returns `false`            |
| `add()`     | throws exception           |
| `poll()`    | returns `null`             |
| `remove()`  | throws exception           |
| `peek()`    | returns `null`             |
| `element()` | throws exception           |

👉 🔥 **Key Idea for Exams:**

* `offer/poll/peek` → **safe methods**
* `add/remove/element` → **exception methods**

---

## 🔹 Flow of Queue (FIFO)

```
Insert → Rear (Tail)
Remove → Front (Head)
```

Example:

```
[10, 20, 30]

poll() → removes 10
Result → [20, 30]
```

---

## 🔹 Code Explanation (Step-by-Step)

```java
Queue<Integer> q = new LinkedList<>();
```

👉 Queue reference, LinkedList object

---

```java
q.offer(10);
q.offer(20);
q.offer(30);
```

👉 Adds elements at **rear**

Queue becomes:

```
[10, 20, 30]
```

---

```java
q.peek();
```

👉 Returns front → `10` (does NOT remove)

---

```java
q.poll();
```

👉 Removes front → `10`

Queue becomes:

```
[20, 30]
```

---

## 🔹 Final Output

```
Queue: [10, 20, 30]
Front: 10
Removed: 10
After removal: [20, 30]
```
