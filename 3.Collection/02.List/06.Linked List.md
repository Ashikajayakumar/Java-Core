# 🔹 What is LinkedList in Java?
<img width="1024" height="1536" alt="image" src="https://github.com/user-attachments/assets/ac5245d7-bc1f-454e-a8a0-bf19661df200" />

### ✅ Definition

* 👉 **LinkedList** is a class in Java that uses a **doubly linked list** to store elements.
* 👉 It is part of the **Java Collections Framework**.

## 🔹 Simple Meaning

👉 LinkedList = **Nodes connected using links**

Each element (node) contains:

```text
[ Data | Previous | Next ]
```

## 🔹 Doubly Linked List Structure

```text
NULL ← [10] ⇄ [20] ⇄ [30] → NULL
```

👉 You can traverse:

* Forward ➡️
* Backward ⬅️

# 🔹 Class Declaration (Corrected)

```java
public class LinkedList<E> 
    extends AbstractSequentialList<E> 
    implements List<E>, Deque<E>, Cloneable, Serializable
```

# 🔹 Key Features (Your Notes — Corrected)

* ✔ Allows **duplicate elements**
* ✔ Maintains **insertion order**
* ✔ Non-synchronized (not thread-safe)
* ✔ Uses **doubly linked list**
* ✔ No shifting of elements ✔️

---

# 🔹 Why LinkedList?

### 1️⃣ Fast Insertion & Deletion 🔥

```java
list.add(1, 50);
list.remove(2);
```

* 👉 No shifting needed
* 👉 Only pointer change ✔️

---

### 2️⃣ Dynamic Size

👉 No fixed size limit

---

### 3️⃣ Works as Multiple Data Structures

👉 Can act as:

* List
* Stack
* Queue
* Deque

```java
list.addFirst(10); // stack-like
list.addLast(20);  // queue-like
```

---

# 🔹 When to Use LinkedList?

✔ When:

* Frequent **insertions/deletions**
* Data changes often

❌ Not good when:

* Frequent **random access (get)**
  👉 Because traversal is required (slow ❌)

---

# 🔹 Example

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        LinkedList<Integer> list = new LinkedList<>();

        list.add(10);
        list.add(20);
        list.addFirst(5);

        System.out.println(list);
    }
}
```

👉 Output:

```text
[5, 10, 20]
```

---

# 🔹 LinkedList vs ArrayList (Very Important 🔥)

| Feature       | ArrayList      | LinkedList            |
| ------------- | -------------- | --------------------- |
| Structure     | Dynamic Array  | Doubly Linked List    |
| Access        | Fast (O(1)) ✔️ | Slow (O(n)) ❌         |
| Insert/Delete | Slow ❌         | Fast ✔️               |
| Memory        | Less           | More (extra pointers) |

# 🔹 Complete LinkedList Operations Program

```java id="llfullprog"
import java.util.*;

public class Main {
    public static void main(String[] args) {

        // 1️⃣ Create LinkedList
        LinkedList<Integer> list = new LinkedList<>();

        // 2️⃣ Add elements
        list.add(10);
        list.add(20);
        list.add(30);

        System.out.println("After adding: " + list);

        // 3️⃣ Add at beginning & end
        list.addFirst(5);
        list.addLast(40);

        System.out.println("After addFirst & addLast: " + list);

        // 4️⃣ Insert at specific position
        list.add(2, 15);
        System.out.println("After inserting at index 2: " + list);

        // 5️⃣ Access elements
        System.out.println("First element: " + list.getFirst());
        System.out.println("Last element: " + list.getLast());
        System.out.println("Element at index 3: " + list.get(3));

        // 6️⃣ Update element
        list.set(3, 25);
        System.out.println("After updating index 3: " + list);

        // 7️⃣ Remove elements
        list.removeFirst();
        list.removeLast();
        list.remove(2);

        System.out.println("After removing elements: " + list);

        // 8️⃣ Remove by value
        list.remove(Integer.valueOf(20));
        System.out.println("After removing value 20: " + list);

        // 9️⃣ Print using for loop
        System.out.print("Using for loop: ");
        for (int i = 0; i < list.size(); i++) {
            System.out.print(list.get(i) + " ");
        }

        // 🔟 Print using for-each loop
        System.out.print("\nUsing for-each: ");
        for (int num : list) {
            System.out.print(num + " ");
        }

        // 1️⃣1️⃣ Size
        System.out.println("\nSize of list: " + list.size());
    }
}
```
