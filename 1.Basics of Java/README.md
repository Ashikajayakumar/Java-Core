## 🧩 Mini Definitions

* **JDK** → Java Development Kit (tools to develop Java programs)
* **JRE** → Java Runtime Environment (runs Java programs)
* **JVM** → Java Virtual Machine (executes bytecode)
* **First Program** → Basic structure of Java program (`main` method)
* **Data Types** → Define type of data (int, float, etc.)
* **Variables** → Store data values
* **Literals** → Fixed values in code
* **Casting** → Type conversion
* **Operators** → Perform operations (+, -, *, etc.)
* **Control Statements** → Decision making (if, switch, loops)
* **Methods** → Reusable blocks of code
* **Arrays** → Collection of same type elements
* **String** → Sequence of characters
