 <h2 align="center"><b>🧩 Step 1: Java Source Code</b></h2>

  ```File.java```

   * This is human-readable code.


<h2 align="center"><b>⚙ Step 2: Compiler (javac)</b></h2>
    The Java compiler converts:

```.java  →  .class```

* The `` .class`` file contains bytecode
* Bytecode is not machine code, but an intermediate code understood by JVM.



<h2 align="center"><b>📦 Step 3: Bytecode (.class)</b></h2>

```
 * Output of the Java compiler
 * Stored in .class file
 * Platform independent
 * Understood by JVM
```


<h2 align="center"><b>🧠 Step 4: Inside JVM (Main Part of Diagram)</b></h2>

```
* Once bytecode enters the JVM, two things can execute it:

1️⃣ Interpreter

-> Reads bytecode line by line
-> Converts to machine code
-> Slower but starts quickly
```

```
2️⃣ JIT (Just-In-Time) Compiler

Converts frequently used bytecode into native machine code
Makes program faster after some time

👉 Interpreter = Start fast
👉 JIT = Run fast
```


<h2 align="center"><b>🟢 Step 5: Machine Code (Executable)</b></h2>


After JVM processing, bytecode becomes:
Machine Code → Executable on that OS

````

```
.java (source code)
   ↓
Compiled by javac
   ↓
.class (bytecode)
   ↓
Executed by JVM (Interpreter + JIT)
   ↓
Converted to Machine Code
   ↓
Runs on OS (Linux / Windows / macOS)
```
