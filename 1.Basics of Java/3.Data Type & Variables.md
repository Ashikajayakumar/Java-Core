## 🧩 1. Data Types in Java

Java data types are divided into **two main categories**:

### ✅ A. Primitive Data Types (Basic)

These store **actual values**.

#### 🔸 Non-Numeric Types

* **boolean** → true / false
* **char** → single character (e.g., 'A')

#### 🔸 Numeric Types

👉 **Integer Types**

* `byte` (1 byte)
* `short` (2 bytes)
* `int` (4 bytes) ⭐ most used
* `long` (8 bytes)

👉 **Floating Point Types**

* `float` (4 bytes)
* `double` (8 bytes) ⭐ more precise

---

### ✅ B. Non-Primitive Data Types (Reference)

These store **addresses (references)**.

Examples:

* `String`
* `Array`
* `Class`
* `Interface`

---

## 🧩 2. Variable Declaration

A variable is a **container to store data**.

### ✅ Syntax:

```
dataType variableName;
```

### ✅ Example:

```java
int age;
double salary;
char grade;
```

---

## 🧩 3. Variable Initialization

Assigning value to a variable.

### ✅ Syntax:

```
variableName = value;
```

### ✅ Example:

```java
age = 25;
salary = 45000.50;
grade = 'A';
```

---

### ✅ Declaration + Initialization Together

```java
int age = 25;
double salary = 45000.50;
char grade = 'A';
```

---

## 🧩 4. Variable Naming Rules

### ✅ 1. Must start with:

* Letter (`a-z`, `A-Z`)
* `_` (underscore)
* `$` (dollar)

```java
int age;     // valid
int _count;  // valid
int $salary; // valid
```

❌ Invalid:

```java
int 2age; // starts with number
```

---

### ✅ 2. Can contain:

* Letters
* Digits
* `_`, `$`

```java
int myAge2;
int total$;
int _value_1;
```

---

### ❌ 3. Cannot use Java keywords

```java
int class; // invalid
```

---

### ✅ 4. Case Sensitive

```java
int age;
int Age; // different
```

---

### ✅ 5. Use meaningful names (Best Practice)

```java
int score; // good
int x;     // not recommended
```

---

# 🧩 5. Types of Variables in Java

## 🔸 1. Local Variable
```
✔ Declared inside method/block
✔ Must be initialized before use
✔ Scope is limited
```

```java
void display() {
    int x = 10; // local variable
    System.out.println(x);
}
```

---

## 🔸 2. Instance Variable
```
✔ Declared inside class (outside method)
✔ Each object has its own copy
✔ Default values assigned automatically
```

```java
class Student {
    int age; // instance variable
}
```

---

## 🔸 3. Static Variable (Class Variable)
```
✔ Declared using `static`
✔ Shared among all objects
✔ Memory allocated once
```

```java
class Student {
    static String college = "ABC College";
}
```
