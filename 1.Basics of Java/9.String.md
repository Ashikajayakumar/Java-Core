## 🧩 What is a String?

In Java, a **String** is an **object** that represents a sequence of characters.

```java
String s = "Hello";
```

👉 Internally, it behaves like a character array:

```java
char[] ch = {'j','a','v','a'};
String s = new String(ch);
```

---

# 🔷 How to Create a String Object?

## ✅ 1. Using String Literal (Recommended)

```java
String s = "welcome";
```
```
✔ Stored in **String Constant Pool (SCP)**
✔ Memory efficient (no duplicate objects)
```
---

## ✅ 2. Using `new` Keyword

```java
String s = new String("welcome");
```

⚠ Important:

* Creates **2 objects**

  1. One in **Heap**
  2. One in **String Pool (if not already present)**

---

# 🔷 Immutable String in Java

👉 **Immutable = Cannot be changed**

```java
String s = "hello";
s.concat(" world");
System.out.println(s);
```

👉 Output:

```
hello
```
``
✔ Why? Because:

* A **new object** is created → original remains unchanged

✔ To actually change:
``
```java
s = s.concat(" world");
```

---

## 🔥 Why Strings are Immutable?
``
* Security (passwords, URLs)
* Thread safety
* Performance (String pool reuse)
``
---

# 🔷 Mutable Strings in Java

## ✅ 1. StringBuffer

```java
StringBuffer sb = new StringBuffer("Hello");
sb.append(" World");
System.out.println(sb);
```

✔ Output:

```
Hello World
```

✔ Features:

* Mutable (changeable)
* **Thread-safe (synchronized)**

---

## ✅ 2. StringBuilder

```java
StringBuilder sb = new StringBuilder("Hello");
sb.append(" World");
System.out.println(sb);
```

✔ Features:

* Mutable
* **Not synchronized**
* Faster than StringBuffer

---

# 🔷 Difference: String vs StringBuffer

| Feature     | String         | StringBuffer |
| ----------- | -------------- | ------------ |
| Mutability  | Immutable      | Mutable      |
| Performance | Slow (new obj) | Faster       |
| Thread-safe | Yes            | Yes          |

---

# 🔷 Difference: StringBuffer vs StringBuilder

| Feature       | StringBuffer   | StringBuilder      |
| ------------- | -------------- | ------------------ |
| Introduced    | Java 1.0       | Java 1.5           |
| Thread Safety | ✅ Synchronized | ❌ Not synchronized |
| Speed         | Slower         | Faster             |
| Use Case      | Multi-thread   | Single-thread      |

# 🔷 How to Create Immutable Class?

✔ Rules:

1. Declare class as `final`
2. Make all variables `private final`
3. No setters
4. Initialize via constructor
5. Return copies (for mutable objects)

### ✅ Example:

```java
final class Student {
    private final int id;

    public Student(int id) {
        this.id = id;
    }

    public int getId() {
        return id;
    }
}
```

# 🔷 toString() Method

👉 Converts object into String

```java
class Student {
    int id;
    String name;

    public String toString() {
        return id + " " + name;
    }
}

public class Main {
    public static void main(String[] args) {
        Student s = new Student();
        s.id = 1;
        s.name = "John";

        System.out.println(s); // calls toString()
    }
}
```

✔ Output:

```
1 John
```
