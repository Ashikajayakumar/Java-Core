# 📘 Java Collections & Framework – Complete Notes
# 🔷 1. What is Collection in Java?

## 🔹 Definition

👉 A **`java.util.Collection`** is an **interface** that represents a **group of objects as a single unit**.

## 🔹 What is an Interface?

👉 An **interface** is a **blueprint of a class**

It contains:

* ✔ Method declarations (no body)
* ✔ Constants (final variables)

---

## 🔹 Simple Meaning

Instead of storing values separately:

```java
int a = 10, b = 20, c = 30;
```

👉 We use a collection:

```java
ArrayList<Integer> list = new ArrayList<>();
list.add(10);
list.add(20);
list.add(30);
```

✔ Here, `list` stores multiple objects together

---

## 🔹 Why Collection?

Collections are used to:

* ✔ Store multiple objects
* ✔ Handle dynamic data (size can grow/shrink)
* ✔ Perform operations like:

* Searching
* Sorting
* Insertion
* Deletion

---

# 🔷 2. What is Framework in Java?

---

## 🔹 Definition

👉 A **Framework** is a **predefined set of classes, interfaces, and rules** that provides a **structure to build applications**

---

## 🔹 Simple Meaning

👉 Framework = **Skeleton / Structure of a program**

---

## 🔹 Why Framework?

* ✔ Saves development time
* ✔ Reduces code complexity
* ✔ Provides reusable components
* ✔ Follows best practices

---

# 🔷 3. Java Collections Framework (JCF)

---

## 🔹 Definition

👉 The **Java Collections Framework** is a set of:

* ✔ Interfaces
* ✔ Classes

👉 Used to store and manipulate data efficiently

---

## 🔹 Interfaces

* List
* Set
* Queue
* Deque

---

## 🔹 Classes

* ArrayList
* LinkedList
* HashSet
* TreeSet
* PriorityQueue

---

## 🔹 Example

Without framework:

```java
int[] arr = new int[10]; // fixed size
```

With framework:

```java
ArrayList<Integer> list = new ArrayList<>();
list.add(10);
```

✔ More flexible and powerful

---

# 🔷 4. Types of Frameworks

---

✔ Collection Framework → Data handling
✔ Web Framework → Example: Spring
✔ Testing Framework → Example: JUnit

---

# 🔷 5. Framework vs Library 🔥

| Feature | Framework               | Library          |
| ------- | ----------------------- | ---------------- |
| Control | Framework controls flow | You control flow |
| Usage   | Structure-based         | Function-based   |
| Example | Spring                  | Utility classes  |

# 🔷 6. Types of Objects in Java (Collections)

---

## 🔹 1️⃣ Homogeneous Objects

### ✅ Definition

👉 Collection stores **same type of objects**

---

### 💡 Example

```java
ArrayList<Integer> list = new ArrayList<>();

list.add(10);
list.add(20);
list.add(30);
```

✔ Output:

```
[10, 20, 30]
```

---

## 🔹 2️⃣ Heterogeneous Objects

### ✅ Definition

👉 Collection stores **different types of objects**

---

### 💡 Example

```java
ArrayList list = new ArrayList();

list.add(10);
list.add("Java");
list.add(3.14);
```

✔ Output:

```
[10, Java, 3.14]
```
